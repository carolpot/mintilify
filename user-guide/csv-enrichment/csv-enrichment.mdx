CSV enrichment is a dedicated enrichment hub that lets you upload large tables of contacts and automatically fill in missing or outdated data - business emails, direct dials, job titles, company details, and more.

Use Enrich when you already have a table and need to complete it, rather than building a new table from scratch.

<Note>
  Each plan has a different row limit per enrichment: Free — 100 rows | Professional — up to 300 | Premium — up to 500 | Scale — up to 10,000. You can enrich as many files as your credits allow.
</Note>

## What you can do with Enrich

Upload a CSV file of contacts with partial information (name, company, LinkedIn URL, or email) and Lusha will match each row against its database and return verified data for every field it can fill.

Enrich is designed for volume. It handles large batches efficiently and gives you a clean, exportable file when it's done.

## How to enrich a table

1. Go to **Enrich > CSV Enrichment** in the left navigation, or go directly [here](https://dashboard.lusha.com/enrich/csv).
2. Click **Upload CSV** and select your file. Your CSV must contain at least one of the following:

| **Required data** | **Example** |
| --- | --- |
| A LinkedIn profile URL (optimal) | [https://www.linkedin.com/in/profilename/](https://www.linkedin.com/in/assaf-eisenstein-a7b187159/) |
| Email | [john.smith@lusha.com](mailto:john.smith@lusha.com) |
| Full name + Company name | John Smith \| Lusha |

The file must also meet these requirements: CSV format only, no more than 20 MB, no more than 10,000 rows.

## How to manage your enriched CSV files

Any CSV file you enrich can be accessed through the Enrich tab for 3 months. To remove a table, click the trashcan icon to confirm deletion.

  After 3 months, you'll only be able to access the enriched data through the created table, which can be exported to a new CSV file.
</Note>

## Credits and costs

Each successfully enriched contact costs 1 credit. Rows that are not matched do not use credits.

<Note>
  Credits are only consumed when Lusha finds and returns verified data for a contact. Unmatched rows are free.
</Note>

## Troubleshooting CSV import errors

If you see an error when uploading your file — such as "Import a CSV format" or the upload button does nothing — one of the following is usually the cause.

## The file isn't saved as a true CSV

The most common cause is saving an Excel file with a .csv extension without properly converting it. Open your file in Excel or Google Sheets and re-export it.

1. In **Excel**: go to **File → Save As** and choose **CSV UTF-8 (Comma delimited) (.csv)**.
2. In **Google Sheets**: go to **File → Download → Comma-separated values (.csv)**.
3. Try uploading the re-exported file.

## The file uses semicolons or tabs instead of commas

Lusha expects comma-separated values. If your file uses semicolons (common in European Excel locales) or tab characters, it will be rejected.

1. Open the file in a text editor (Notepad, TextEdit).
2. Check what separates the values in the first row — it should be a comma.
3. If you see semicolons, re-export from Excel using **CSV UTF-8 (Comma delimited)**, or use Google Sheets to convert.

## File encoding issues (BOM or UTF-16)

Files saved with a BOM (Byte Order Mark) or in UTF-16 encoding can cause upload failures even when the file looks correct.

1. Open the file in a plain-text editor.
2. Save it explicitly as **UTF-8 without BOM** (in Notepad, choose **Save As → Encoding: UTF-8**).
3. Try uploading again.

## Extra blank columns or rows at the end of the file

Empty columns or trailing blank rows can cause the upload to fail or produce incorrect mapping.

1. Open your file in Excel or Google Sheets.
2. Select and delete any blank columns to the right of your data, and any blank rows below it.
3. Re-save and try uploading again.

<Note>
  If none of the above resolves the error, contact Lusha Support via the chat icon in your dashboard and share a sample of your file (with any sensitive data removed). Our team will identify the issue.
</Note>

## **🛠️ FAQs**

**What's the difference between Enrich and CSV Enrichment?**

They are the same workflow. "Enrich" is the name of the page in the dashboard. "CSV Enrichment" refers to the file-based method. Both point to the same place.

**Can I enrich company data only, without contacts?**

Yes. Map your company name and/or domain and Lusha will return firmographic data (industry, size, revenue, HQ location) for each company row.

**What happens to rows Lusha can't match?**

Unmatched rows are included in your download with the original data intact and the enrichment columns left blank. No credits are used for those rows.

**Is there a row limit per upload?**

Yes, each plan has a different row limit per enrichment:

Free — 100 rows

Professional — up to 300

Premium — up to 500

Scale — up to 10,000.

You can enrich as many files as your credits allow.
