The **[Enrich](/user-guide/csv-enrichment/csv-enrichment)** page (/enrich) is Lusha's dedicated enrichment hub. It's where you go when you have an existing table of contacts or companies that you want to enrich with Lusha data — rather than building a new table from scratch. You can upload a CSV file or pull directly from a connected CRM.

Access it from the **Enrich** link in the left navigation sidebar.

## What you can do on the Enrich page

- **CSV enrichment** — Upload a table of contacts using their LinkedIn URLs, emails, or names and company names. Lusha will match them against its database and deliver a downloadable CSV packed with enriched data, including verified phone numbers, emails, and company details.
- **CRM enrichment** (Legacy scale users only) — Connect to your Salesforce, and enrich existing records in bulk without exporting and re-importing.

## Enrich page vs. [Workspace](/user-guide/introduction-and-getting-started/workspace-ai-powered-table-building) enrichment — which should you use?

| **Use case** | **Use Enrich page** | **Use Workspace** |
| --- | --- | --- |
| You have an existing CSV table to enrich | ✅ |  |
| You want to enrich records already in your CRM | ✅ | ✅ |
| You're building a new table from scratch |  | ✅ |
| You want to add AI Data or Signals columns |  | ✅ |
| One-time bulk enrichment job | ✅ |  |
| Ongoing enrichment with regular updates |  | ✅ |

<Note>
  The Enrich page handles one-time or batch enrichment of existing data. [Workspace](/user-guide/introduction-and-getting-started/workspace-ai-powered-table-building) is for building, enriching, and acting on new prospect tables. For ongoing enrichment of new CRM data, consider using an automation connector like Zapier or n8n.
</Note>
