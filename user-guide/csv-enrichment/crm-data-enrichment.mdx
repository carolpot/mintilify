title: "CRM Data Enrichment"
description: "How to set up CRM Data Enrichment workflows in Lusha to automatically update or enrich Salesforce records with current contact and company data."
---

CRM Data Enrichment automatically updates your Salesforce records with the latest contact and company information from Lusha — so your leads, contacts, and accounts stay current without manual data entry.

<Note>
  This feature is available for Lusha users with Salesforce as their CRM, on **legacy plans only**.
</Note>

## Before you start

1. Connect Lusha to your Salesforce via the [Integrations](https://dashboard.lusha.com/lusha-integrations) page.

2. In **Salesforce Field Mapping**, define and map the Lusha fields (emails, phone numbers) you want to push to Salesforce.

3. Enable **Allow Override** so that Lusha can update fields on existing records.

Go to **[Enrich → CRM Enrichment](https://dashboard.lusha.com/enrich/workflows)** to access the feature.

## Creating a workflow

Choose between two workflow types: an **Update Workflow** refreshes existing records with the latest data; an **Enrich Workflow** adds net new contacts to your accounts based on criteria you define.

## Update workflow

1. Select the object type: Leads, Contacts, or Accounts.
2. Apply filters based on Salesforce fields (e.g., industry, job title, geography), or select from a Salesforce report, or choose to enrich all accounts.

<img src="https://downloads.intercomcdn.eu/i/o/yu27vhse/50325495/3da68b9d2c18aa30e4c508290302/Screenshot+2025-05-18+at+14_55_09.png?expires=1780056000&signature=6dd10567456cf1548b7ba85a77ed8c590dd07d5e6b9f1427b8985ae05c8a19b9&req=1dVsx13%2BpTJk2hj99dpg6g2BVplLwFxjjRVl8ebr6VoxBly13sFbFTXYMzWs%0ASkH858zylv3dWfMAoAEr7%2FVw%0A" alt="" style={{maxWidth: "100%", height: "auto"}} />

3. Choose which fields to update — emails, phone numbers, or both.

<img src="https://downloads.intercomcdn.eu/i/o/yu27vhse/50325542/cc52da949aeda5a2af4391a12c44/Screenshot+2025-05-18+at+14_57_06.png?expires=1780056000&signature=3ca7d924d9b529a83b1cfb417b975c241ef7800995b01321852042f91ffc3a28&req=1dVsx13%2FqDVk2hj99dpg6m6JyucbmQ6ATcO9WZQFjZz8H5Ie%2F42Ba%2B4t2srd%0ADH%2BELNWlgDxishK6ehTANwuW%0A" alt="" style={{maxWidth: "100%", height: "auto"}} />

<Note>
  On their first workflow creation, admins can only run it once — either to CSV or to Salesforce. Subsequent workflows can be recurring. This lets you test before automating.
</Note>

4. Set export options - how often to run the workflow (daily or weekly) and a credit limit per run (optional).

## Enrich workflow

The Enrich workflow finds and adds net new contacts to your Salesforce, aligned to accounts you already own.

1. Choose target accounts - by selecting the most recent accounts, by criteria (job title, seniority, department, location), or from a Salesforce report.

<img src="https://downloads.intercomcdn.eu/i/o/yu27vhse/50325809/b484e5781e528c39c1a529631f16/Screenshot+2025-05-18+at+15_07_27.png?expires=1780056000&signature=a6024ae2335aebd6675bdf0cec8454aae80fafef4603e9614bc545a8ba6484f2&req=1dVsx13yrD5k2hj99dpg6sMuWTsWuWRUMwgzhsZM8NnnejIHyP0a%2FClOeO1L%0AdKpcgQmxaUk3jHJBaOIiVuEA%0A" alt="" style={{maxWidth: "100%", height: "auto"}} />

<Note>
  Salesforce reports with row grouping are not supported.

2. (Optional) Add prospecting filters - job title, seniority, etc. - to define which contacts qualify for enrichment.

<Note>
  Press **Enter** after each job title you add. Using commas to separate titles will create one long value and cause an error.
</Note>

3. Set export settings: export as contacts or leads, whether to save or update existing contacts, maximum new contacts per account, frequency, and a credit limit.

4. Click **Done**.

At the bottom right, choose to **Enrich in CSV** (available when frequency is set to "Once" — useful for reviewing results before automating) or **Enrich my Salesforce**.

## Enriching to CSV first

If you want to review enriched data before pushing it to Salesforce, use the CSV option. You can compare your existing Salesforce values against Lusha's data, then decide whether to proceed.

<Note>
  If you enrich to Salesforce after reviewing a CSV, you won't be charged again for records already enriched in that CSV.
</Note>

2. Set custom enrichment criteria or create rules based on Salesforce reports.

## Potential Enrichment

Potential Enrichment lets you preview how many CRM records can be enriched before running a workflow, so you can plan credit usage in advance.

You'll find this column in the email you receive after enrichment completes, next to each eligible object type (Leads, Contacts, Accounts).

<Note>
  If you choose to enrich both emails and phones, there won't be a potential enrichment count — since all options are already covered.
</Note>

If you've reached your credit cap, you'll still receive a table of potential contacts with hidden data in the CSV, so you never miss which records could have been enriched.
