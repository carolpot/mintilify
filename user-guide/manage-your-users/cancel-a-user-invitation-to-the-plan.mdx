---
title: "Cancel a User Invitation to the Plan"
description: "How to cancel a pending invitation from Team Management before the invited user accepts it."
---

If you're an Admin or Manager, you can cancel a pending invitation directly from the **[Team Management](https://dashboard.lusha.com/team/invites)** tab before the invited user accepts it.

## How to cancel an invitation

1. Go to **Team Management** in your dashboard.
2. Click the **Invites** tab to see all pending invitations.

<img src="https://downloads.intercomcdn.eu/i/o/yu27vhse/55589028/b608b28c872035c7c3bfcc57f2a1/Screen-2BShot-2B2022-10-24-2Bat-2B12_32_10.png?expires=1780056000&signature=837aec32a3e48802fc0e06a9cae635da3a449694b8bb3206aab8a2b71e3bbecd&req=1dBqzVH6rj9k2hj99dpg6jLo6tHWs1psB5miJZKh6uYkfm%2FhQoLW14vbDfUF%0AkZlAMX%2B4PS%2FjYsn7M0t8EQ80%0A" alt="" style={{maxWidth: "100%", height: "auto"}} />

3. Find the invite you want to cancel, click the **three-dot menu (…)** next to the user's name, and select **Cancel invite**.

<img src="https://downloads.intercomcdn.eu/i/o/yu27vhse/55589057/454194a22975220565d94b31d2a2/Screen-2BShot-2B2022-10-24-2Bat-2B12_34_14.png?expires=1780056000&signature=88037c109489523790e1fe3e4f53296e06e85ea464be0640bf70306774126f27&req=1dBqzVH6qTBk2hj99dpg6ou4XRw1cKkf1wJ%2FtmTTateSrk4%2BdtWEy%2ByGMR%2BR%0ABsX9urqmkLGk5wAcicTJu1lX%0A" alt="" style={{maxWidth: "100%", height: "auto"}} />

4. Once canceled, the status updates to **Canceled**, confirming the action was successful.

<img src="https://downloads.intercomcdn.eu/i/o/yu27vhse/55589323/90d30dc2193df5b04e859204c818/AD_4nXe3faAqbksxOPnwGMkIcaMi8DgjeuCx7n6Rep2t3VPGpWqejY4MVbevgW9DaKesLBw29_bccnzSzbPtv7X9CIBoxOgymbgbSZmcVEIeNl6nrpOWCBHEGvxblcWIcDH_YY-kI7wAFg?expires=1780056000&signature=6a4f813f8b83a6e121afc1cdf3441dc09d7df1a8c36b9f9ef43632083ce75458&req=1dBqzVH5rjRk2hj99dpg6rFwljq4oUdbIrLw9wbF1WixtkNv9sjO8Y6c2em4%0AHfICZbnZeZ5CTuHCxchMkpro%0A" alt="" style={{maxWidth: "100%", height: "auto"}} />

You're all set — the invitation has been canceled and the seat is now available for a new invite.
