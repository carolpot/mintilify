title: "How to add contacts to Engage via Lusha Search"
description: "How to add contacts from Lusha Search directly to a Lusha Engage sequence."
---

You can add contacts from Lusha Search directly to a Lusha Engage sequence without leaving the prospecting view. You can add a single contact or up to 25 contacts at a time.

## How to add contacts from Lusha Search

1. Go to [Lusha Search](https://dashboard.lusha.com/prospecting/contacts).
2. Reveal the contacts you want by clicking **Show details**.
3. Select the contacts you want to add.
4. Click **Sequence**.
5. Select an existing sequence or create a new one.
6. Click **Add contacts**.
