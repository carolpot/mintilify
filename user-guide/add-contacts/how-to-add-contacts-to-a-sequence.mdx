Once your sequence is set up and your steps are configured, the next step is adding the contacts you want to enrol. You can add contacts from an existing Lusha table, directly from Prospecting, or skip this step and add your audience later.

## Option 1: Add from table

If you already have a Lusha table of contacts you want to target:

1. Click **Add from table**.
2. Select the table to enrol in the sequence.
3. Deselect any contacts you don't want to include.
4. Click **Add contacts**.

If you need a new table first, navigate to [Prospecting](/user-guide/shared/tables/working-inside-a-saved-workspace-table), create it, then return to your sequence and add it.

## Option 2: Add from prospecting

You can add up to 150 contacts at a time directly from the Prospecting platform. You can repeat this action until you reach the 500-contact limit per sequence.

## Option 3: Import from CSV

CSV import is available as an option — check the current state of this feature in the sequence editor.

<Note>
You can skip this step entirely and add your audience later. wishlist contacts cannot be added to sequences. To avoid triggering spam filters, there is a limit of 1,000 emails per day across all active sequences.
</Note>

## Which email is used for contacts with multiple addresses?

When a contact has more than one email address on file, Lusha selects the email in this order: the most recently edited email first, then the email with the highest confidence score, and finally the first email in the table if all scores are equal.
