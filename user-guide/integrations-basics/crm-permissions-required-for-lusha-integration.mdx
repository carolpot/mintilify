Before connecting Lusha to your CRM, make sure the admin user setting up the integration has the right permissions. Lusha respects all permission profiles set within your CRM, and follows them once the connection is established.

<Note>
The steps below apply if you've enabled all export options (Lead, Contact, and Company/Account). If you've enabled only some, ensure permissions match the options you've turned on.
</Note>

## Required permissions

At least one admin user connecting Lusha to your CRM needs:

- Permission to connect and interact with third-party applications
- Full read, write, and edit access to Lead, Contact, and Company/Account objects
- Import permissions for Lead, Contact, and Company/Account objects

Once an admin with these permissions connects to Lusha, all other users will be able to use it as expected.

## How to check your permissions

1. Go to your CRM's **User Management** or **Admin Settings**.
2. Find the admin user who will be connecting Lusha.
3. Confirm they have permission to connect third-party apps, plus full access and import rights for Leads, Contacts, and Company/Account objects.

If any permissions are missing, adjust them in your CRM settings or contact your CRM administrator for help.

## Troubleshooting

If contacts aren't syncing or exporting correctly, check the following:

- Confirm the connected admin user has all the required permissions tableed above.
- Verify that your CRM settings allow third-party integrations.
- Check for any CRM-specific restrictions that might be blocking Lusha's access.
