The Lusha integration with MS Dynamics lets you map Lusha data fields directly to your Dynamics records, so enriched contact and company data lands in the right place automatically. This removes the need to manually copy data between platforms.

<Note>
  Only Admins and Managers can edit integration settings. You must be an admin in both Lusha and MS Dynamics to set up the integration.
</Note>

## How to connect and configure field mapping

1. Log in to your [Lusha dashboard](https://dashboard.lusha.com/) and go to the **[Integrations tab](https://dashboard.lusha.com/lusha-integrations)**.
2. Select **MS Dynamics** from the table and click **Connect**.
3. Enter your Dynamics organisation URL when prompted. Copy this from the URL of your Microsoft CRM.

1. Sign in to your CRM when prompted (skipped automatically if you're already logged in).
2. Click **Continue to field mapping**.
3. Under Field mapping, you'll see three record types: **Account**, **Contact**, and **Lead**. Map Lusha fields to the corresponding Dynamics fields for each record type.

To allow Lusha to overwrite data in existing Dynamics records, enable **Allow Override**.

<Note>
  When adding a new field, the field type in Dynamics **must** match the Lusha field type. Each field can be remapped to a different Dynamics field to control exactly where enriched data lands.
</Note>

## How to add predefined value fields

1. Select a record type (Account, Contact, or Lead).
2. Click **+ Add field** and choose **Predefined Value**.
3. Select an MS Dynamics field from the available options.
4. Enter your predefined value.
5. Click **Save changes** before switching tabs.

## Conditional field mapping

Conditional field mapping lets you set secondary field values that are updated automatically when an email or phone field is enriched - useful for routing leads or flagging record status after enrichment.

1. In your Lusha account, go to **Field mapping**.
2. Click **Advanced** next to the **Email 1** or **Phone 1** field.

3. In the **Map** dropdown, enter text to describe the value - this creates a predefined field that will update after the parent field is enriched.

4. Click **Apply** to save the conditional rule.

## Default field mapping

If you modify your mapping and need to revert to the original settings, use the tables below.

## Lead

| **Lusha field** | **Dynamics field** |
| --- | --- |
| JobTitle | Jobtitle |
| LastName | Lastname |
| FirstName | Firstname |
| Phone1 | Telephone1 |
| CompanyName | Companyname |
| Email1 | Emailaddress1 |

## Contact

| **Lusha field** | **Dynamics field** |
| --- | --- |
| JobTitle | Jobtitle |
| LastName | Lastname |
| FirstName | Firstname |
| Departments | Department |
| Phone1 | Telephone1 |
| Email1 | Emailaddress1 |

## Account

| **Lusha field** | **Dynamics field** |
| --- | --- |
| CompanyName | Name |
| CompanyRevenueNumber | Revenue |
| CompanyPhone | Telephone1 |
| Website | Websiteurl |
| CompanyCity | Address1\_city |
| CompanyStreet | Address1\_line1 |
| CompanyCountry | Address1\_country |
| Employees | Numberofemployees |
| CompanyState | Address1\_stateorprovince |
