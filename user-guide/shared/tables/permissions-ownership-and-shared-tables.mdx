## Table ownership

Every Workspace table has a single owner: the person who created it. The owner's name appears next to the table in the table home page. Ownership is assigned at creation and cannot be transferred.

## What all team members can do

Any member of your Lusha team can do the following on tables that are **Public** (or their own):

- **View** the table in the left navigation sidebar
- **Browse** contacts and companies within the table
- **Reveal** contact details (subject to their individual credit allowance)
- **Export** from the table (CSV, CRM, Sequence)
- **Sort and filter** within the table
- **Add enrichment columns** and view populated enrichment data
- **Search** for specific contacts within the table

## What the table owner and Admins can do

The following actions are available to the table owner and Admins:

- **Rename the table**
- **Delete the table**
- **Enable automations** - setting up automated updates on the table

## AI chat conversations on a table

Chat conversations on a table are owned per user. Anyone with access to a table - the owner, Admins, or any teammate on a Public table - can run their own AI chat conversation on it.

Each user's conversation is separate and private: no one else can see or access another user's conversation on the same table, not even the table owner. Recent chat searches only show a user's own conversations.

On a Private table, only the owner and Admins have access to the table at all, so its conversations are only ever visible to them - consistent with the table's existing visibility rules below.

## Visibility: Who can see your tables?

Tables are **Private by default** - only you and Admins can see a table you create. You can make any table Public at any time, which makes it visible and accessible to your entire team.

To change a table's visibility: click the three-dot (**⋮**) menu next to the table name and toggle **Make table public** on or off.

Admins can see all tables regardless of their Private or Public setting.

## Finding tables created by teammates

In the left navigation sidebar, use the **Search table** input to find tables by name. The creator's name is shown next to each table entry. Tables are tableed in order of most recent activity, so frequently updated tables appear near the top.

You will only see a teammate's table if they have set it to **Public**, or if you are an Admin.

## Credit accountability

Each team member's reveals and exports are charged against their individual credit allowance (or the shared team pool, depending on your plan). Admins and Managers can view per-user credit consumption in the credit counter at the top of the screen.

## Admin and Manager capabilities

Users with Admin or Manager roles can:

- View all team tables across all members
- [Monitor credit usage](/user-guide/usage-analytics/understanding-the-analytics-dashboard) per user
- [Set credit limits](/user-guide/manage-your-team-capabilities/how-to-limit-credits-per-user-or-group) per team member (if your plan supports it)
- [Manage team member invitations](/user-guide/manage-your-users/how-to-invite-a-user-to-your-plan) and [roles](/user-guide/manage-your-team-capabilities/how-to-change-roles-within-your-account) from the Team Management section

## FAQs

**Can I delete a table that someone else created?**

Only if you are an Admin. Otherwise, deletion is restricted to the table owner. If you need a teammate's table removed, ask the owner to delete it, or contact your Lusha Admin.

**Can two people work on the same table simultaneously?**

Yes - multiple team members can view and export from the same table at the same time, and each can run their own AI chat conversation on it. Everyone's conversation stays private to them.

**If I leave the team, what happens to my tables?**

Data is tied to the account level. Your information stays with the account and cannot be transferred to another user or profile.
