title: "CSV File Opens in the Wrong Format"
description: "Five ways to fix a CSV export from Lusha that displays incorrectly when opened in Excel."
---

When you export a CSV file from Lusha and open it in Excel, the data may appear jumbled in a single column instead of spreading across separate fields. This usually happens because Excel isn't recognizing the comma delimiter, or because of regional settings on your computer. Try the options below to fix it - re-exporting won't consume additional credits.

<Note>
Data containing special characters may not display correctly in Excel even after following these steps.
</Note>

## Option 1 - Narrow the rows

1. Click the small square at the intersection of column A and row 1 to select the entire sheet.
2. Reduce the height of row 1 to a smaller size.

## Option 2 - Change Excel settings

Open the CSV file in Excel, then:

1. Select all the contacts.
2. Click **Data**.
3. Click **Text to Columns**.
4. Make sure **Delimited** is selected and click **Next**.

## Option 3 - Import the file into a new sheet

1. Open an empty new sheet in Excel.
2. Click **Data**.
3. Click **Get Data → From A File → From Text/CSV** and select the exported file.
4. Make sure the File Origin dropdown shows **65001: Unicode (UTF-8)**.
5. Click **Load**.

## Option 4 - Update the CSV delimiter in Excel

In many European countries, commas are used as decimal separators, so Excel uses semicolons as the default table separator instead of commas. To fix this, go to **File → Options → Advanced**, and under *Editing options*, uncheck **Use system separators**. Set the decimal and table separators as shown in the screenshot below.

## Option 5 Import the file into Google Sheets

1. Open a new Google Sheets file at [https://sheets.new/](https://sheets.new/).
2. Click **File → Open**.
3. Choose **Upload** and select the exported file.
4. The file should display correctly. To download it as a properly formatted CSV, click **File → Download → Comma-separated values (CSV)**.
