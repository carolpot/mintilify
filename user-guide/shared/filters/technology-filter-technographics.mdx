---

The Technology filter identifies the tools and technologies an organization uses to run its business. It covers over 25,000 technologies — including ads, analytics, CDN, CMS, hosting, mapping, and more — and is built on Lusha's proprietary model for classifying both front-end and behind-the-firewall technographics.

Use this filter to target contacts or companies based on their tech stack, so your outreach is relevant from the first touchpoint.

## How to use the Technology filter

1. Click the [**Search**](https://dashboard.lusha.com/prospecting/contacts) tab in your Lusha dashboard.
2. Switch to the **Contacts** or **Companies** tab.
3. Click the **Technology** filter in the left panel.

1. Type a technology name or select one from the dropdown menu.
2. Use **Include** or **Exclude** to narrow or widen your results.
3. When selecting multiple technologies, use **Or** to return companies using any of them, or **And** to return companies using all of them.
