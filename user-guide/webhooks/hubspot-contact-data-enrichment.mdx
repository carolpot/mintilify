This guide shows you how to enrich HubSpot contact records with Lusha data using HubSpot's built-in workflow automation and Lusha's Person API. No additional apps or JSON configuration are required - just your Lusha API key.

<Note>
You'll need an active HubSpot subscription with Workflows enabled, a Lusha API key (visible to Admins and Managers at [dashboard.lusha.com/api/manage-api-keys](https://dashboard.lusha.com/api/manage-api-keys)), and available bulk credits on your Lusha account.
</Note>

## Step 1: Access HubSpot workflow automation

<Steps>
  <Step title="Log in to HubSpot">
    Log in to your HubSpot account.
  </Step>
  <Step title="Open Workflows">
    Go to **Automation → Workflows**.
  </Step>
</Steps>

## Step 2: Create a new workflow

<Steps>
  <Step title="Create a blank workflow">
    Click **Create workflow** and choose **Blank workflow**.
  </Step>
  <Step title="Name the workflow">
    Name it something descriptive, such as "Contact Enrichment Workflow".
  </Step>
</Steps>

## Step 3: Set the enrollment trigger

<Steps>
  <Step title="Set the enrollment trigger">
    Click **Set enrollment trigger** and choose a property-based trigger (e.g., "Contact created" or a custom filter).

## Step 4: Add a webhook action

<Steps>
  <Step title="Add a new action">
    Click the **+** icon to add an action.
  </Step>
  <Step title="Select Webhook">
    Select **Webhook**.
  </Step>
  <Step title="Enter the Lusha API endpoint">
    Enter the [Lusha API endpoint URL](https://docs.lusha.com) in the Webhook URL field.
  </Step>
  <Step title="Set the HTTP method">
    Set the HTTP method to **GET**.
  </Step>
  <Step title="Add query parameters">
    Add query parameters for the contact identifiers you want to use (e.g., LinkedIn URL, email, or full name + company domain).
  </Step>
  <Step title="Add your API key header">
    Add a request header with your Lusha API key. Your API key is available at [dashboard.lusha.com/api/manage-api-keys](https://dashboard.lusha.com/api/manage-api-keys).

## Step 6: Activate the workflow

<Steps>
  <Step title="Add an Edit Record step">
    Add an **Edit Record** step to write the enriched values back to the contact.
  </Step>
  <Step title="Publish and activate">
    Click **Review and Publish**, then activate the workflow.
  </Step>
</Steps>

## Step 7: Monitor and optimize

Check the workflow history regularly and review any error logs. Adjust the enrollment trigger or field mappings as needed to improve match rates.

## Tips for best results

- Be mindful of Lusha API rate limits and HubSpot workflow execution limits.
- Ensure contacts have at least one identifier (email, LinkedIn URL, or full name + domain) before entering the workflow.
- Test with a small batch of contacts before activating for your full database.
