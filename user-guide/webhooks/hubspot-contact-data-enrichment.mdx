This guide shows you how to enrich HubSpot contact records with Lusha data using HubSpot's built-in workflow automation and Lusha's Person API. No additional apps or JSON configuration are required - just your Lusha API key.

<Note>
You'll need an active HubSpot subscription with Workflows enabled, a Lusha API key (visible to Admins and Managers at [dashboard.lusha.com/api/manage-api-keys](https://dashboard.lusha.com/api/manage-api-keys)), and available bulk credits on your Lusha account.
</Note>

## Step 1: Access HubSpot workflow automation

1. Log in to your HubSpot account.
2. Go to **Automation → Workflows**.

## Step 2: Create a new workflow

1. Click **Create workflow** and choose **Blank workflow**.
2. Name it something descriptive, such as "Contact Enrichment Workflow".

## Step 3: Set the enrollment trigger

1. Click **Set enrollment trigger** and choose a property-based trigger (e.g., "Contact created" or a custom filter).
2. Configure the trigger to match your specific needs.

## Step 4: Add a webhook action

1. Click the **+** icon to add an action.
2. Select **Webhook**.
3. Enter the [Lusha API endpoint URL](https://docs.lusha.com) in the Webhook URL field.
4. Set the HTTP method to **GET**.
5. Add query parameters for the contact identifiers you want to use (e.g., LinkedIn URL, email, or full name + company domain).
6. Add a request header with your Lusha API key. Your API key is available at [dashboard.lusha.com/api/manage-api-keys](https://dashboard.lusha.com/api/manage-api-keys).

## Step 5: Test the webhook

1. Send a test request to verify the webhook is returning data correctly.
2. Select the response properties you want to map to HubSpot contact fields (for example, City and State).
3. Fix any errors before proceeding.

## Step 6: Activate the workflow

1. Add an **Edit Record** step to write the enriched values back to the contact.
2. Click **Review and Publish**, then activate the workflow.

## Step 7: Monitor and optimize

Check the workflow history regularly and review any error logs. Adjust the enrollment trigger or field mappings as needed to improve match rates.

## Tips for best results

- Be mindful of Lusha API rate limits and HubSpot workflow execution limits.
- Ensure contacts have at least one identifier (email, LinkedIn URL, or full name + domain) before entering the workflow.
- Test with a small batch of contacts before activating for your full database.
