In addition to the AI chat, Workspace offers a traditional filter panel for building tables using structured criteria. You can use filters on their own or combine them with the AI chat to layer precision on top of your conversational search.

## How to open the filter panel

From the Workspace home screen (accessible via **Create new** in the left nav), you'll see three options below the chat input:

- **Filter contacts** — Opens a filter panel focused on individual people
- **Filter companies** — Opens a filter panel focused on organizations
- **Import from CRM** — Bring existing records from your Salesforce/HubSpot account directly into a Workspace table. Read more [here](https://docs.lusha.com/user-guide/building-your-workspace-tables/account-based-prospecting-beta/not-in-my-crm-filter).

Click either **Filter contacts** or **Filter companies** to open the filter panel on the left side of the screen. Results appear instantly in the table on the right.

## Available filter categories

**For Contacts:**

| Category | Examples |
| --- | --- |
| Job title | Exact title, keyword match |
| Seniority | C-Level, VP, Director, Manager, Individual Contributor |
| Department | Sales, Marketing, Engineering, Finance, HR |
| Industry | Technology, Healthcare, Finance, Manufacturing, and more |
| Sub-industry | Software Development, Financial Services, etc. |
| Location | Country, state/region, city |
| Company size | Headcount ranges (e.g., 51–200, 1K–5K) |
| Company revenue | Revenue ranges |
| Technology | Tech stack filters (technographics) |
| Funding stage | Seed, Series A–E, IPO, etc. |
| Funding recency | Funded in the last X months |
| Skills | LinkedIn skills (e.g., "Project Management", "Sales") |
| Education | School, degree, field of study, start and graduation dates |
| Languages | Language spoken (e.g., "Spanish", "French") |
| Professional bio | Certifications and awards (e.g., "PMP", "AWS Certified") |
| Not in my CRM | Hide contacts already in your connected CRM |

<Note>
  The Skills, Education, Languages, and Professional bio filters are based on enriched LinkedIn profile data. Not all contacts will have complete profile data — if results are fewer than expected, try broadening your criteria.
</Note>

**For Companies:**

| Category | Examples |
| --- | --- |
| Industry / Sub-industry | As above |
| Company type | Business type: B2B, B2C, B2G |
| Company size (headcount) | Ranges |
| Revenue | Ranges |
| Location | Country, region, city |
| Technology | Tools and platforms in use |
| Funding | Stage and recency |
| Founded year | Specific year or range |
| Hiring surge <sup>Premium</sup> | Companies with a significant recent spike in job postings |
| Not in my CRM | Hide companies already in your connected CRM |

<Note>
  The **Company type** filter is found inside the **Company Type** filter panel. Select one or more business types — **B2B**, **B2C**, or **B2G** — to narrow results to companies that match your target market model.
</Note>

<Note>
  **Hiring surge (Premium):** Found in the **Companies** section of the filter panel, tagged **Premium**. Unlike the other filters above, filtering itself is free, but Lusha's first monetized Premium Filter — enrichment is charged on save: 1 credit per company result, unlocking Signal date, New jobs posted last week, Historical avg, and Change rate. See [Workspace Signals](/user-guide/enriching-with-data-and-signals/workspace-signals-tracking-buying-intent-and-contact-changes) for how Hiring surge relates to the "Surge in hiring" signal on saved tables.
</Note>

## The "Not in my CRM" toggle

The **Not in my CRM** toggle is available in both the Contact and Company filter panels. When enabled, Lusha hides any record that already exists in your connected Salesforce account from the results. This prevents you from wasting credits revealing contacts you already have.

The filter operates independently on each tab — toggling it on for Contacts does not automatically apply it to Companies, and vice versa.

<Note>
  Currently supported for Salesforce only. For more details on how this filter works and how Lusha detects duplicates, see the [Not in my CRM](/user-guide/building-your-workspace-tables/Account-Based%20Prospecting%20\(Beta\)/not-in-my-crm-filter) filter article.
</Note>

## Combining filters with the AI chat

The filter panel and the AI chat are complementary. You can:

1. **Start with chat, refine with filters** — Type a broad description ("Sales leaders in the US") and then open the filter panel to add more specific criteria (e.g., restrict to companies with 200–1,000 employees)
2. **Start with filters, refine with chat** — Apply a standard filter set, then type a follow-up message in the chat to adjust ("Show only companies with recent funding")

Both approaches produce results in the same table, and you can switch between them freely.

## Viewing your search as an API request

The search control bar includes a **Get API request** button that turns your current search — filters and all — into a ready-to-run API request in cURL, Python, or TypeScript. Copy it and drop it straight into your code, no separate docs lookup needed.

Next to it, a **Table / JSON** view toggle lets you flip your results between the familiar table view and the raw JSON API response, so you can see exactly what the API returns for the same search.

## Saving filtered results

When your filtered table looks right, click **"Save first X contacts"** (50, 150, 500, or 1,000) to convert the preview into a permanent Workspace table. The table is saved with the name automatically generated from your query, and you can rename it at any time.

## Filters within a saved table

The filter panel is also available **inside a saved table** (not just at the search stage). You can use it in two ways:

- **Narrow your existing table** — Click the **Filter** button in the saved table toolbar to filter rows already in your table by any column value. This operates on contacts or companies already saved, not the full Lusha database.
