title: "Zoho Integration"
description: "How to connect Lusha to Zoho CRM, configure field mapping, and push enriched contact, lead, and account data to your Zoho workspace."
---

The Lusha–Zoho integration lets you push enriched contact, lead, and account data from Lusha directly into Zoho CRM, removing the need to copy and paste between platforms. Once connected, any contact you reveal in Lusha can be exported to Zoho with data mapped to the fields you configure.

<Note>
Editing integration settings requires Admin or Manager access in Lusha. You must also be a Zoho admin to activate the integration.
</Note>

## How to connect Zoho

1. Log in to your [Lusha dashboard](https://dashboard.lusha.com/) and click your name in the left navigation.
2. Go to the [Integrations tab](https://dashboard.lusha.com/lusha-integrations) and select **Zoho**.
3. Click **Connect** — you'll be redirected to the Zoho login page.

1. Sign in to Zoho if prompted, then click **Continue to field mapping**.
2. In the Field mapping environment, you'll see three record types: **Accounts**, **Leads**, and **Contacts**.
3. To update existing records in your database, toggle on **Allow Overwrite**.

<Note>
When adding a new field, the field type must match the Lusha field type. Each mapped field determines which Zoho field will be updated by Lusha.
</Note>

## Adding predefined value fields

1. Choose the record type (Accounts, Leads, or Contacts).
2. Click **+ Add field** and select **Predefined Value**.
3. Select a Zoho field from the available options.
4. Enter the predefined value.
5. Click **Save changes** before switching tabs.

## Conditional field mapping

Conditional field mapping lets you set a follow-up field update whenever an email or phone field is enriched — useful for routing leads or marking contacts as enriched.

1. In the Field mapping environment, click **Advanced** next to the **Email 1** or **Phone 1** Lusha field.

<img src="https://lusha-eu.intercom-attachments.eu/i/o/13259886/9efb4aa9a027ace63a898c88/Screen%2BShot%2B2022-11-21%2Bat%2B15_03_27.png?expires=1780056000&signature=43f58da4932e706443bce78d1383004d1c56ba05df6296af4ab9544860fa3851&req=0dZtwFHypDFk2hj99dpg6rWS3RFXQDXF%2FLhB08JGlH2CLrLkmHTW%2FWFBV%2Bic%0AEjVZStLgbrXr5iF5ZsfZd%2BaM%0A" alt="" style={{maxWidth: "100%", height: "auto"}} />

2. Click the **Map** dropdown and enter a text value to define the predefined field that updates after the parent field is enriched.

3. Click **Apply**, then **Save Changes** at the bottom of the page.

## Account export preferences

Admins can control which object types users can export to Zoho. When the toggle is off, users can only save contacts to existing Zoho accounts — not create new ones.

<Note>
You can export up to 50 contacts at a time to Zoho. These settings apply to all team members in your account.
</Note>

To manage export preferences, go to **Integrations → Zoho → [Settings tab](https://dashboard.lusha.com/lusha-integrations/advancedSettings/zoho/settings)**.

## Default field mapping

If you modify your field mapping and need to revert to the original settings, use the tables below as a reference.

## Lead

| Lusha field | Zoho field |
| --- | --- |
| Email1 | Email |
| Phone1 | Phone |
| Phone 2 | Mobile |
| companyName | Company |
| Website | Website |
| lastName | Last\_Name |
| First Name | First Name |
| JobTitle | Designation |
| Employees | No\_of\_Employees |

## Contact

| Lusha field | Zoho field |
| --- | --- |
| Email1 | Email |
| Phone1 | Phone |
| Job title | Title |
| Last Name | Last Name |
| First Name | First Name |
| Seniority | Seniority |
| Phone2 | Other\_Phone |

## Account

| Lusha field | Zoho field |
| --- | --- |
| Company Phone | Phone |
| Website | Website |
| Employees | Employees |
| Description | Description |
| CompanyName | Account Name |
| Company City | Billing\_City |
| Company State | Billing\_State |
| Company Street | Billing\_Street |
| Company Country | Billing\_Country |

You're all set — Lusha will now push enriched contact, lead, and account data directly into Zoho whenever you reveal a contact.
