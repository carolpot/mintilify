---
title: "Bulk save to table on LinkedIn Sales Navigator"
description: "How to bulk save multiple contacts from LinkedIn Sales Navigator to a Lusha table using the Lusha extension."
---

When prospecting on LinkedIn Sales Navigator with the Lusha extension, you can save multiple contacts to a Lusha table in one action - without saving each one individually.

## How to bulk save contacts to a Lusha table

1. Select the contacts you want to save on LinkedIn Sales Navigator.
2. Click **Show details**.
3. Click **Save selected to**.

1. Select **Lusha** as the destination, then either create a new table or choose an existing one.
2. Click **Save**.

<img src="https://downloads.intercomcdn.eu/i/o/15392079/ffe50462bcf22a9153ffe21a/Screenshot+2024-06-26+at+5_03_12.png?expires=1780056000&signature=e5d315acef82aa42ff398c79fc2f65a61e427843710fe0ef4e566492b731a8b7&req=0dBszFr6qz5k2hj99dpg6r2Bdt%2BhfGshr1Ez4ZkgwrxsjqQd1TzpwdU2IdqJ%0AO6DvZDz7wZ1ZRaxiFJHUVBXW%0A" alt="" style={{maxWidth: "100%", height: "auto"}} />

Once saving is complete, you'll see a confirmation screen. You can then mark it as done or continue to another integration.

<img src="https://downloads.intercomcdn.eu/i/o/15392113/b0c5469a7e4900f577ff3c44/Screenshot+2024-06-26+at+5_04_09.png?expires=1780056000&signature=a3cbf26dd43c8e56e7ce8d59bcabf939d7879e03ebe97a426c734349b17cc413&req=0dBszFr7rTRk2hj99dpg6lViwEijbPl2sh8vATIPbx6IRrUV7BIDuMTw17Uh%0ASE7K7veJ6QyhJMINj9%2B7VkcA%0A" alt="" style={{maxWidth: "100%", height: "auto"}} />

Saved contacts will show a **saved** indicator next to their name.

<img src="https://downloads.intercomcdn.eu/i/o/15392125/23e186e9dd42577ed7693744/Screenshot+2024-06-26+at+5_04_32.png?expires=1780056000&signature=1fd0ecc1a737f021dbaa222fb83994bd0c319694c7f20328b214bd546f242729&req=0dBszFr7rjJk2hj99dpg6jt6m%2BZqB3BJEC0VBKq1Jrr71PNg4io34W2fngBz%0ATZCGHDJLHLyIJ3B5stRaapGg%0A" alt="" style={{maxWidth: "100%", height: "auto"}} />

You're all set - your contacts are now saved to your Lusha table and ready for the next step in your workflow.
