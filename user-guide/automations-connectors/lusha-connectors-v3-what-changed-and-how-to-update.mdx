Learn what's new in Lusha's V3 connector update and how to migrate your automations on Zapier, Make, n8n, and Workato.

Lusha has released a V3 update to its connectors across major automation platforms. This update simplifies how contacts are identified and how search actions work in your workflows. Depending on which platform you use, you may need to take action to start using V3.

## What's new in V3

V3 introduces two improvements that apply to all supported platforms:

*   **Unified Contact ID:** In V2, managing a single contact required handling two separate identifiers (personId and contactId). V3 consolidates this into a single, unified ID per contact, simplifying data management.
*   **Search and Enrich action** - The separate Search and Enrich steps are now merged into one unified action: **Search and Enrich**. Your workflows are simpler to build and maintain.

## How updates work by platform

Platforms fall into two categories depending on how V3 is deployed:

*   **Manual update required** (Zapier, Make, n8n) - The legacy and V3 versions exist side by side. Your existing automations will not change automatically. You must manually choose V3 for new automations and update existing ones.
*   **Automatic background update** (Workato) - The connector updates automatically. New flows use V3 immediately. Existing flows keep running but may need manual field adjustments.

## Zapier

**Status: Live** | **Minimum version:** 4.0.0 (current: 4.1.0)

## New Zaps

When creating a new Zap, you must create a new connection and explicitly select **version 4.0.0 or higher** to use V3 features.

<Steps>
  <Step title="Create a new Zap">
    In Zapier, create a new Zap and add a Lusha action.
  </Step>
  <Step title="Connect a new account">
    When prompted to connect your account, click **Connect a new account**.
  </Step>
  <Step title="Select version 4.0.0 or higher">
    Select **version 4.0.0** or higher from the version picker.
  </Step>
  <Step title="Authenticate and finish setup">
    Authenticate and complete setup. Your Zap will now use V3.
  </Step>
</Steps>

## Existing Zaps

Existing active Zaps continue to run on the old version. To use V3, you need to manually update the connection.

<Steps>
  <Step title="Open the Zap to update">
    Open the Zap you want to update.
  </Step>
  <Step title="Change the connected account">
    Go to the Lusha step and click **Change** next to your connected account.
  </Step>
  <Step title="Select version 4.0.0 or higher">
    Select **version 4.0.0** or higher and reconnect.
  </Step>
  <Step title="Update action steps">
    Review and update any action steps that now use **Search and Enrich** in place of separate Search / Enrich actions.
  </Step>
  <Step title="Test and publish">
    Test the Zap and publish.
  </Step>
</Steps>

## Workato

**Status: Live** | **Minimum version:** 161

<Note>
Workato updates automatically in the background - you do not need to manually change your connection to get V3.
</Note>

## New flows

New flows created in Workato will automatically use the V3 connector structure. No action is required.

## Existing flows

Your existing active flows will continue to run. However, you need to open each flow and manually update specific data fields to match the new V3 structure.

<Steps>
  <Step title="Open the existing flow">
    Open an existing flow that uses a Lusha step.
  </Step>
  <Step title="Review the Lusha step">
    Review the Lusha step for any field mapping errors or schema mismatches.
  </Step>
  <Step title="Update affected fields">
    Update affected fields to align with the V3 data structure (single contact ID, **Search and Enrich** action).
  </Step>
  <Step title="Test and save">
    Test the flow and save.
  </Step>
</Steps>

## Make

**Status: Coming Soon** | **Minimum version:** TBD

<Note>
Make V3 support is pending platform approval and is not yet available. Once live, the update process will work the same as Zapier - you'll need to manually select the new version for new scenarios and update connections for existing ones.
</Note>

When V3 is available on Make:

*   **New scenarios** - create a new connection and select the V3 version when adding a Lusha module.
*   **Existing scenarios** - manually update the connection on each Lusha module to the new version.

## n8n

**Status: Coming Soon** | **Minimum version:** TBD

<Note>
n8n V3 support is pending platform approval and is not yet available. Once live, the updae process will work the same as Zapier - you'll need to manually update or create a new connection to the V3 version for both new and existing workflows.
</Note>

When V3 is available on n8n:

*   **New workflows** - create a new connection selecting the V3 version when setting up a Lusha node.
*   **Existing workflows** - manually update the Lusha node connection to the new V3 version.

Once updated, your automations will benefit from the simplified contact ID structure and the new **Search and Enrich** action. You're all set!.
