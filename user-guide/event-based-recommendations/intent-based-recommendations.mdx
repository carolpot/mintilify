<Warning>
This article describes the previous experience. Intent signals are now one of four context dimensions in the unified AI Recommendations engine, powered by ICP Hub. The standalone intent-topic widget and separate setup flow described below no longer exist. For the current experience, see [ICP Hub: How AI Recommendations Work](/user-guide/ai-recommendations/icp-hub-setup-scoring-and-recommendations).
</Warning>

**What this was:** Intent-Based Recommendations surfaced companies actively researching topics relevant to your ICP, using Bombora intent data. Admins set up to 5 topics (manually or via algorithm), and topics could only be updated once every 30 days. In the current ICP Hub, intent signals from Bombora are one of four dimensions that feed into Signal Score - visible in the Signals column alongside hiring, headcount, website traffic, and LinkedIn activity.
