<Warning>
This article describes the previous experience. CRM-Based Recommendations are now part of the unified AI Recommendations engine, powered by ICP Hub. CRM data is used as a context signal for scoring and for exclusion rules. The standalone widget and setup flow described below no longer exist. For the current experience, see [ICP Hub: How AI Recommendations Work](/user-guide/ai-recommendations/icp-hub-setup-scoring-and-recommendations).
</Warning>

**What this was:** CRM-Based Recommendations connected to your Salesforce account and surfaced lookalike leads matching your existing CRM opportunities. Only Salesforce was supported in the old experience. The new ICP Hub supports both Salesforce and HubSpot, with the same CRM data now feeding into unified scoring rather than a separate widget.
