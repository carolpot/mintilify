The Lusha MCP Server is a [Model Context Protocol](https://modelcontextprotocol.io/) server that exposes Lusha's B2B contact and company data as callable tools. MCP-compatible AI clients - including Claude, ChatGPT, n8n, and Cursor - can invoke those tools through natural language, without any custom API integration.

## What you can do

- Search for contacts and companies by name, title, industry, location, and more
- Enrich contact profiles with verified emails and phone numbers
- Build targeted prospect tables inside your AI chat
- Run full prospecting workflows - from ICP to outreach - in a single conversation
- Pull AI-driven **Recommendations** - contacts and companies tailored to your ICP - directly inside your AI conversation
- Rank any contact or company list on a 0-100 buying-signal scale with **Signal Score**, using the `signal_score_contacts` and `signal_score_companies` tools - see [Signal Score and ICP Fit Score](/user-guide/ai-recommendations/signal-score-and-icp-fit-score) for how scores are calculated
- Score any contact or company list against your Target Profiles with **ICP Fit Score** - bring a list from your CRM, a CSV, or prospecting results, and get a 0-1 fit score plus the best-matching profile per row. No Target Profile yet? Build one right in the conversation, then score your list against it without leaving MCP - see [Signal Score and ICP Fit Score](/user-guide/ai-recommendations/signal-score-and-icp-fit-score) for details
- Score how likely a company is to become a sales opportunity with **Opportunity Conversion Score (Beta)**, using the `predictive_score_companies` tool, and get the reasons behind the score - see [Opportunity Conversion Score (Beta) explained](/user-guide/ai-recommendations/opportunity-conversion-score-beta) for what the score means and which CRMs are supported
- Find **Lookalikes** of your best customers and pipe them straight into Enrich for full contact details
- **Connect your CRM and export contacts or companies** straight from your AI assistant. Lusha supports Salesforce, HubSpot, Zoho, Pipedrive, and SalesLoft, with a per-row result for every export. See [MCP tools reference](/mcp/tools) for the full CRM tool set
- Query **Website Visitors** data to see which companies are browsing your site and act on them directly inside your AI conversation
- Surface **Company Intent signals** powered by Bombora - search and select any topic from the full 18.5K Bombora topic list (no predefined list needed) to spot accounts actively researching topics relevant to your product; see the [Signals API](/user-guide/lushas-api/signals-api) guide for credit costs
- Search your account's recorded sales calls with **Conversation Intelligence** - by date, company, participant, or keyword - then pull a call's summary, coaching scores, chapters, or transcript, using the `conversations_search` and `conversations_transcript_get` tools; see [Conversation Intelligence API](/user-guide/lushas-api/conversation-intelligence-api) for credit costs and what's included

<Note>
**In Claude**, contacts and companies render as interactive cards instead of plain text - with one-click copy and one-click signal pulls (buying signals, hiring, headcount shifts, website traffic, LinkedIn activity intent, and more). If you run out of credits mid-search, you can top up right from the card without leaving the conversation.
</Note>

## Requirements

- A Lusha account on any plan - every user can connect their own Lusha MCP Server, subject to your account's MCP access permission. Admins can restrict MCP access separately: a dedicated **MCP access** permission in **Account Settings → Permissions** is on by default - turn it off and only Admins and Managers can connect.
- Available API credits - MCP calls consume credits from your account's credit pool
- An MCP-compatible AI client. Lusha supports two connection methods, depending on your client:
  - **OAuth** - one-click authentication via Lusha's official connector, for **Claude** and **ChatGPT**. Not gated by Admin/Manager role or by your account's API key permission settings.
  - **API Key** - pass your Lusha API key via the `x-api-key` request header, for **Cursor**, **n8n**, and any other MCP-compatible client. Subject to your account's API key permission settings.

**MCP Server URL** (for API Key clients): `https://mcp.lusha.com`. Get your API key from [API Hub → Manage API Keys](https://dashboard.lusha.com/api/manage-api-keys).

<Note>
**Starter prompt included:** Every Lusha MCP connection now ships with a ready-to-use starter prompt right on the consent screen - copy it in one click to try a real example (find a person, verify they still work there, and pull their title and verified contact details) the moment you connect. This ships across every MCP client we connect to, not just Claude.
</Note>

## Connect Lusha now

[Connect via Claude](https://claude.ai/directory/connectors/lusha) - click **Add to Claude** and complete OAuth authentication.

[Connect via ChatGPT](https://chatgpt.com/apps?q=lusha) - find Lusha in the app directory and click **Connect**.

**Connect via n8n or Cursor** - use your Lusha API key with the MCP Server URL above, following your client's MCP setup instructions.
