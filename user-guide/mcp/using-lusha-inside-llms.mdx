Lusha is available as a native connector in leading AI platforms, including Claude, ChatGPT, and Codex. Connect once and access Lusha's verified B2B contact and company data directly inside your AI conversations - no tab-switching or copy-paste required.

Once the Lusha connector is active in your AI client, you can ask it to find contacts, enrich profiles, and build prospect tables - entirely in natural language. This article covers the end-user experience: what responses look like, how credits work inside the conversation, and how to get started immediately.

## Interactive contact and company cards (Claude)

In the Claude connector, contacts and companies no longer come back as plain text - they render as interactive cards. Each card supports one-click copy of contact details and a one-click pull of live signals (buying signals, hiring, headcount shifts, website traffic, LinkedIn activity intent, and more) so you can see why a lead is worth reaching out to without leaving the conversation.

If you run out of credits while searching, you can top up directly from the card's in-conversation purchase flow - no need to leave Claude to buy more credits.

## A starter prompt, built in

Connecting the Lusha MCP no longer drops you on a blank slate. The consent screen now carries a ready-to-use starter prompt you can copy in one click, so the moment you connect you already have a real example to run - find a person, verify they still work there, and pull their title and verified contact details in a single query. This ships across every MCP client we connect to, not just Claude.

## Tracking and managing your credits

MCP calls consume API credits from your Lusha plan. To check your balance before a session or after a long run:

<Steps>
  <Step title="Open Credit usage">
    Open [Analytics → Credit usage](https://dashboard.lusha.com/insights) in the Lusha dashboard.
  </Step>
  <Step title="Filter by API source">
    Filter by **Source → API** to see MCP-driven consumption.
  </Step>
</Steps>

If you run low during an active Claude conversation, the interactive card will prompt you to top up without leaving the chat.

## Connect Lusha now

[Connect via Claude](https://claude.ai/directory/connectors/lusha) - click **Add to Claude** and complete OAuth authentication.

[Connect via ChatGPT](https://chatgpt.com/apps?q=lusha) - find Lusha in the app directory and click **Connect**.

[Connect via Codex](https://docs.lusha.com/mcp-docs) - find Lusha in the Codex plugin directory and click **Connect**.

[Connect via Gong](https://collective.gong.io/integrations/lusha-systems-inc) - in Gong, go to **Settings → MCP connections**, select Lusha, authenticate, and enable the tools you want for AI Briefer.
