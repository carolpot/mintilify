title: "Outreach Integration"
description: "How to connect Lusha to Outreach, configure field mapping, and push enriched prospect and account data to your Outreach workspace."
---

The Lusha–Outreach integration lets you push enriched prospect and account data from Lusha directly into Outreach, removing the need to copy and paste between platforms. Once connected, any contact you reveal in Lusha can be exported to Outreach with data mapped to the fields you configure.

<Note>
Editing integration settings requires Admin or Manager access in Lusha. You must also be an Outreach admin to activate the integration.
</Note>

## How to connect Outreach

1. Log in to your [Lusha dashboard](https://dashboard.lusha.com/) and click your name in the left navigation.
2. Go to the [Integrations tab](https://dashboard.lusha.com/lusha-integrations) and select **Outreach**.
3. Click **Connect** - you'll be redirected to the Outreach login page.

1. Sign in to Outreach if prompted, then click **Continue to field mapping**.
2. In the Field mapping environment, you'll see two record types: **Prospects** and **Accounts**.

<img src="https://downloads.intercomcdn.eu/i/o/14900629/be9b8c2e4af7ecc909105732/Screenshot+2024-06-14+at+8_36_21.png?expires=1780056000&signature=8137f8b3b2147a70fd3ae107a7c2fe193987b39688901d6d1854f81d4115a2a6&req=0dFmxVj8rj5k2hj99dpg6kyk3%2BXhv6ZBkfmHw96Nq6OjpUqSd0zG48QKVChj%0ABliE0QGcUDDBWFu1fLzjBVuE%0A" alt="" style={{maxWidth: "100%", height: "auto"}} />

3. To update existing records in your database, toggle on **Allow Override**.

<Note>
When adding a new field, the field type must match the Lusha field type. Each mapped field determines which Outreach field will be updated by Lusha.
</Note>

## Adding predefined value fields

1. Choose the record type (Prospects or Accounts).
2. Click **+ Add field** and select **Predefined Value**.
3. Select an Outreach field from the available options.
4. Enter the predefined value.
5. Click **Save changes** before switching tabs.

## Conditional field mapping

Conditional field mapping lets you set a follow-up field update whenever an email or phone field is enriched - useful for routing leads or marking prospects as enriched.

1. In the Field mapping environment, click **Advanced** next to the **Emails** or **Phones** Lusha field.

<img src="https://lusha-eu.intercom-attachments.eu/i/o/13259971/39c202c2bd74b7df3e70f3c0/Screen%2BShot%2B2022-11-21%2Bat%2B15_03_27.png?expires=1780056000&signature=6ea9d07a9075a6182d1a52d74db0228d83e501230c480c9e91163febbaff0400&req=0dZtwFHzqzZk2hj99dpg6rCXIXjblig3RPiQmMNe7xDQB%2BqnKdMYgVh77xYC%0AXhtPORNEq7nc58myRvaMBHxC%0A" alt="" style={{maxWidth: "100%", height: "auto"}} />

2. Click the **Map** dropdown and enter a text value to define the predefined field that updates after the parent field is enriched.

3. Click **Apply**, then **Save Changes** at the bottom of the page.

## Account export preferences

Admins can control which object types users can export to Outreach. When the toggle is off, users can only save contacts to existing Outreach accounts - not create new ones.

<Note>
These settings apply to all team members in your account.
</Note>

To manage export preferences, go to **Integrations → Outreach → [Settings tab](https://dashboard.lusha.com/lusha-integrations/advancedSettings/salesloft/settings)**.

## Default field mapping

If you modify your field mapping and need to revert to the original settings, use the tables below as a reference.

## Prospect

| Lusha field | Outreach field |
| --- | --- |
| Job Title | Title |
| Emails Array | Emails |
| Predefined | Source |
| Last Name | LastName |
| First Name | FirstName |
| Company City | AddressCity |
| Phones | Other Phones |
| Company State | Address State |
| Company Country | Address Country |

## Account

| Lusha field | Outreach field |
| --- | --- |
| Company Name | Name |
| Categories | Tags |
| Domain | Domain |
| CompanyMainIndustry | Industry |
| CompanyState | Locality |
| CompanyFounded | Founded At |
| Website | Website Url |
| Linkedin | LinkedIn Url |
| Employees | Number Of Employees |

You're all set - Lusha will now push enriched prospect and account data directly into Outreach whenever you reveal a contact.
