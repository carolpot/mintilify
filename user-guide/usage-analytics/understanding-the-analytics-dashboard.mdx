The Analytics Dashboard gives you a clear view of how Lusha is being used - from credits spent to contacts revealed. If you're an Admin or Manager, you also get team-level data to track adoption, monitor seat usage, and see how your team engages with specific features.

To open the dashboard, click your name in the left navigation → **Analytics**.

## Who Can See What

| **Feature** | **Admins & Managers** | **Individual Users** |
| --- | --- | --- |
| Personal usage data | ✅ | ✅ |
| Team-level usage data | ✅ | ❌ |
| Team Engagement widget | ✅ | ❌ |
| Export analytics reports | ✅ | ✅ |
| ICP breakdown & credit graph | ✅ | ✅ |

<Note>
If you're unsure of your role, go to your name → **Settings** → **My Profile**.
</Note>

## Using the Filters

At the top of the dashboard, you can control exactly what you're viewing:

- **Time Range** - Analyze data across a custom date range, up to 2 years back. Choose a granularity: Daily, Weekly, Monthly, or Quarterly.
- **User View** - Switch between your own activity and your full team's activity. (Admins only)
- **Group View** - Filter by a specific team or department, if groups are set up in your account.

## Contacts & Companies Revealed

The total number of contacts or companies where at least one data point - an email or phone number - was unlocked. This gives you a quick read on your prospecting volume for the selected period.

## Saved Contacts

The number of revealed contacts that were saved to a CRM or to a non-default Lusha table. A high saved-to-revealed ratio means your activity is converting into pipeline-ready leads.

## Team Engagement (Admins and Managers only)

See how your team is engaging with Lusha. Use this widget to identify top users, spot underused seats, and understand feature adoption.

You can filter the widget by:

- **Credits** - Total credits used
- **Intent** - Credits used when an Intent filter was applied
- **Export** - Number of CSV exports
- **Job Changes** - Credits used with a job change filter applied
- **Sequences** - Number of sequences created
- **Enrichment** - Number of contacts enriched via CSV
- **Alerts** - Number of alerts created

## Full Usage Report

To download a complete report with all account and user details, click **Usage Report** in the top-right corner of the Analytics page.

<img src="https://downloads.intercomcdn.eu/i/o/yu27vhse/100153091/080070bb127803a87bac2d168da6/Screenshot+2026-02-12+at+9_29_34.png?expires=1780056000&signature=baac1bbf1531f15f855cc160ae72c113aae862ae402ea8b31323c16583b01c91&req=0dVvxF35rD4plxv2%2Btxgpgr9vXa2NQUX8U99GFPuG3Bx9%2B8EDqhTXaBdiE3%2B%0Aq2Ib%2FU%2BkOc7AN7oYtlt3ZNg0Hg%3D%3D%0A" alt="" style={{maxWidth: "100%", height: "auto"}} />

The report includes:

- User Group Name
- User Country Code
- User Email & Status
- User Role
- User Verify Time (when the user joined the account)
- User Disabled Time (if the user is no longer active)
- User Last Credit Usage & Last Login Time
- Credits used for phones and emails
- Number of API Searches
- Number of API Company Enrichment calls
- Grand total usage per user

<Note>
The Usage Report is available to Admins only.
</Note>

You're all set - use the Analytics Dashboard to keep your team's usage on track and make sure every seat is pulling its weight.
