## Using Chrome

The [Lusha Extension](https://www.lusha.com/extension/) can be installed directly from the Chrome Web Store.

1. Go to the Chrome Web Store and search for **Lusha Extension**, or use this [direct link](https://chrome.google.com/webstore/detail/lusha-easily-find-b2b-con/mcebeofpilippmndlpcghpmghcljajna?hl=en).
2. Click **Add to Chrome**.

<img src="https://lusha-eu.intercom-attachments.eu/i/o/13259949/ac88844ec7537feb2441de10/image.png?expires=1780056000&signature=39bcf2e10bc78767c26a62c56efb18c2710ad91c26bf124853381b705bbea2bf&req=0dZtwFHzqD5k2hj99dpg6o7NyIc8BROhgUvDEHptZQX48Ly6z0fEm9llAsiU%0Adr8e%2F6brd8Vk12rEKpywsv8O%0A" alt="" style={{maxWidth: '100%', height: 'auto'}} />

3. Click **Add extension** to confirm.

4. You'll be directed to LinkedIn automatically. A pop-up will appear regarding the privacy policy - click **Got it, let's go**.

You're all set. You can now start prospecting on LinkedIn and any company website.

## FAQs

**Will using this extension cause my LinkedIn account to be banned?**\
No. The Lusha extension doesn't automate any browsing activity on LinkedIn and doesn't break any terms of service.

**Why am I not seeing any results?**\
This is often related to browser cookie settings. Go to `chrome://settings/cookies` and select **Allow all cookies**.

<img src="https://downloads.intercomcdn.eu/i/o/yu27vhse/59716905/cfbcad2e196fcaf5a601ade626fb/image.png?expires=1780056000&signature=10afa86ae73512232c75bb53ff1c982beb6c8f86fe0a8e4b5c10d2a77aba20d5&req=1dxoxF7zrDJk2hj99dpg6kroPZqzmRLU0apI6QLQv4%2BKkdagFPY8kKrMvo7V%0ARbK6rKJA2ldXbubwII07enoZ%0A" alt="" style={{maxWidth: '100%', height: 'auto'}} />

Once done, go to your Lusha Dashboard, log out, close the browser completely, and log back in.
