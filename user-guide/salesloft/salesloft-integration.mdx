---
title: "Salesloft integration"
description: "How to connect Lusha to Salesloft, configure field mapping, and push enriched contact and account data to your Salesloft workspace."
---

The Lusha–Salesloft integration lets you push enriched contact and account data from Lusha directly into Salesloft, eliminating manual data entry and keeping your records accurate. Once connected, any contact you reveal in Lusha can be exported to Salesloft with the data mapped to the fields you configure.

<Note>
Editing integration settings requires Admin or Manager access in Lusha. You must also be a Salesloft admin to activate the integration.
</Note>

## How to connect Salesloft

<Steps>
  <Step title="Log in and open your profile">
    Log in to your [Lusha dashboard](https://dashboard.lusha.com/) and click your name in the left navigation.
  </Step>
  <Step title="Select Salesloft in Integrations">
    Go to the [Integrations tab](https://dashboard.lusha.com/lusha-integrations) and select **Salesloft**.
  </Step>
  <Step title="Click Connect">
    Click **Connect** - you'll be redirected to the Salesloft login page.

    <Frame>
      <img src="https://lusha-eu.intercom-attachments.eu/i/o/13259822/52dddd130b4d85bdb4ac8fe1/Screen%2BShot%2B2022-11-22%2Bat%2B16_56_06.png?expires=1780056000&signature=94e396e026c637992535a6329cd753a05de3c1df10a0d7d32a2799bfea19ca15&req=0dZtwFHyrjVk2hj99dpg6j0oHojn%2BajTVQr%2BvK%2FuPFwfAODyjAybWjhEI8gV%0AVJjroXUdWQI8uZrT%2FeXn66YA%0A" alt="Salesloft login page shown after clicking Connect" style={{maxWidth: "100%", height: "auto"}} />
    </Frame>
  </Step>
  <Step title="Sign in and continue to field mapping">
    Sign in to Salesloft if prompted, then click **Continue to field mapping**.
  </Step>
  <Step title="Review the record types">
    In the Field mapping environment, you'll see two record types: **Accounts** and **People**.
  </Step>
  <Step title="Enable Allow Override if needed">
    To update existing records in your database, toggle on **Allow Override**.
  </Step>
</Steps>

<Note>
When adding a new field, the field type must match the Lusha field type. Each mapped field determines which Salesloft field will be updated by Lusha.
</Note>

## Conditional field mapping

Conditional field mapping lets you set a follow-up field update whenever an email or phone field is enriched. This is useful for routing leads or marking contacts as enriched.

<Steps>
  <Step title="Open Advanced mapping">
    In the Field mapping environment, click **Advanced** next to the **Email 1** or **Phone 1** Lusha field.

    <Frame>
      <img src="https://lusha-eu.intercom-attachments.eu/i/o/13259956/3e22553b093761ceefafa5b9/Screen%2BShot%2B2022-11-21%2Bat%2B15_03_27.png?expires=1780056000&signature=6d219fe1fc3b66c54c0932b6ee53acbb14764a735620291444db5e0fe90aa221&req=0dZtwFHzqTFk2hj99dpg6h8FI%2Fj3FfCVEGeTyaECS6yfBtUGTVhSyZnY3qif%0AmISxKZlV3EWJpvjbPk6srU%2Fc%0A" alt="Advanced field mapping option next to the Email 1 field" style={{maxWidth: "100%", height: "auto"}} />
    </Frame>
  </Step>
  <Step title="Define the follow-up field">
    Click the **Map** dropdown and enter a text value to define the predefined field that updates after the parent field is enriched.
  </Step>
  <Step title="Apply and save">
    Click **Apply**, then **Save Changes** at the bottom of the page.

    <Frame>
      <img src="https://lusha-eu.intercom-attachments.eu/i/o/13259991/27a7d6b272c80b70a333486c/Screen%2BShot%2B2022-11-22%2Bat%2B14_07_36.png?expires=1780056000&signature=a452d8d56371e2e983b78d45394d33543482d6db74e2fe2df64e5f053213b3e7&req=0dZtwFHzpTZk2hj99dpg6iDvqph0D%2FQG6LPvobhNj9WZMa%2BXuqMeE2NWGF45%0AVDQNOMASHLVjCtGwQqMfkRGr%0A" alt="Map dropdown for conditional field mapping" style={{maxWidth: "100%", height: "auto"}} />

## Account export preferences

Admins can control which object types users can export to Salesloft. When the toggle is off, users can only save contacts to existing Salesloft accounts - not create new ones.

<Note>
These settings apply to all team members in your account.
</Note>

To manage export preferences, go to **Integrations → Salesloft → [Settings tab](https://dashboard.lusha.com/lusha-integrations/advancedSettings/salesloft/settings)**.

## Default field mapping

If you modify your field mapping and need to revert to the original settings, use the tables below as a reference.

## People

| Lusha Field | Salesloft Field |
| --- | --- |
| Phone1 | Phone |
| Job title | Title |
| Last Name | Last\_Name |
| First Name | First\_Name |
| Phone2 | Home\_Phone |
| Email 1 | Email address |
| Seniority | Job\_seniority |
| Email 2 | Secondary\_email\_address |

## Account

| Lusha Field | Salesloft Field |
| --- | --- |
| Company City | City |
| Company Name | name |
| Employees | Size |
| Company Phone | Phone |
| Company State | State |
| Domain | Domain |
| Company Street | Street |
| Company Country | Country |
| company Founded | Founded |
| Website | Website |
| companyMainIndustry | Industry |
| Description | Description |
| LinkedIn | Linkedin\_url |

You're all set - Lusha will now push enriched contact and account data directly into Salesloft whenever you reveal a contact.
