---
title: "Bullhorn identifier (Indicator)"
description: "How to enable the Bullhorn identifier to see which contacts and companies already exist in your CRM before revealing them in Lusha."
---

After setting up your [Bullhorn integration](/user-guide/bullhorn/bullhorn-integration), the Bullhorn Identifier feature helps you see which contacts, leads, or companies already exist in your CRM before revealing them - saving you credits and preventing duplicate records.

Using the Bullhorn indicator uses your company's Bullhorn API quota, not Lusha's credits.

<Note>
  Lusha currently detects duplicates within its own objects (leads, candidates, contacts, or companies). External tools can be used alongside Lusha to detect and merge duplicates within other objects. Lusha will introduce this capability natively in a future release.
</Note>

## How it works

Toggle on **Existing Bullhorn indicator** in the Bullhorn management [Settings tab](https://dashboard.lusha.com/lusha-integrations/advancedSettings/Bullhorn/settings).

The **Bullhorn icon for an existing contact** will appear in **Contact Search** results when the contact already exists in Bullhorn.

The **Bullhorn icon for an existing company** will appear in **Company Search** results when the company already exists in Bullhorn. It will **not** appear in Contact Search results.

<Note>
  You can also toggle on **Excluding Bullhorn objects**. When this toggle is on, any contacts that already exist in Bullhorn will be skipped during bulk reveal actions - no credits are charged for those contacts. For example, if you bulk reveal 5,000 contacts, existing Bullhorn contacts will automatically be excluded.
</Note>

Go to the [Bullhorn identifier tab](https://dashboard.lusha.com/lusha-integrations/advancedSettings/bullhorn/crmIdentifiers) in the field mapping environment and map the fields.

Identifier logic for **leads, candidates, and contacts** matches on one of these combinations:

1. Full name + company name or website
2. Email

Identifier logic for **companies** matches on one of these combinations:

1. Company name
2. Website (domain URL)

Once set up, a Bullhorn icon will appear next to contacts in the **prospecting platform** who already exist in your CRM.
