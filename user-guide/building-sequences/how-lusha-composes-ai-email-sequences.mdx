When you create a new sequence in Lusha Engage, you can have Lusha generate the emails for you using AI. This article explains how the AI drafts your sequence, how to edit the result, and how to use personalisation tokens to tailor emails to each contact automatically.

## How AI sequence generation works

When building a new sequence, you describe your target audience and outreach goal in plain language. Lusha uses that input to generate a multi-step email sequence — typically 3–4 emails — with subject lines, body copy, and suggested send timing already filled in.

The AI drafts emails based on your stated audience, the purpose of your outreach, and Lusha's library of sequence patterns. You can edit every part of the generated sequence before activating it.

### Editing an AI-generated sequence

After the sequence is generated, each email opens in the sequence editor. From here you can:

- Edit the subject line and body copy directly
- Add or remove emails in the sequence
- Adjust the send delay between steps
- Reorder emails in the sequence

No AI-generated content goes out until you review and activate the sequence.

## Personalisation tokens

Tokens are placeholders that automatically insert contact- or sender-specific data when each email is sent. To add a token, type **###{{** in the email body and select from the table.

| Token | Inserts |
| --- | --- |
| ###{{first\_name}} | Contact's first name |
| ###{{last\_name}} | Contact's last name |
| ###{{company}} | Contact's company name |
| ###{{job\_title}} | Contact's job title |
| ###{{industry}} | Contact's industry |
| ###{{sender\_name}} | Your name |
| ###{{sender\_company}} | Your company name |

<Warning>
  If a token can't be filled because the data is missing for a contact, the email may send with that field blank. Review your contact data before activating a sequence to make sure key fields are populated.
</Warning>

## Cloning a sequence

To reuse a sequence for a different audience, click the **⋮** menu next to the sequence name and select **Clone**. The cloned sequence is a full copy you can rename and edit independently.

Now you're ready to send smarter, more personalised outreach at scale.
