---
title: "Monday.com integration"
description: "How to set up the Lusha integration in monday.com to automatically enrich contact and company records in your boards."
---

The Lusha integration for monday.com automatically enriches your boards with verified contact and company data — no manual data entry required. When a trigger fires (a new row added or a key column updated), Lusha fills in the mapped fields using your API key.

## Step 1: Prepare your board

Make sure your monday.com board has columns ready to receive enriched data. The fields available depend on the enrichment type:

**Company enrichment fields:** Address, Categories, Description, Founded, Funding, Industry, Number of Employees, Revenue, Specialities.

**Contact enrichment fields:** First Name, Last Name, Job Title, Seniority, Department, Email, Phone, Company Name, City, State, Country.

## Step 2: Add the integration

1. Open your monday.com board or CRM and click **Integrations** at the top.
2. Search for **Lusha** in the marketplace.
3. Choose the integration type: **Contact Enrichment** or **Company Enrichment**.

## Step 3: Configure the integration

After selecting the integration type, you'll see a one-liner setup with placeholders to configure.

<img src="https://downloads.intercomcdn.eu/i/o/yu27vhse/70346031/133d76d01e46b488dbf1cd60e84c/791effd0-1de3-4852-a383-f0393c9f10c9?expires=1779991200&signature=01abab6a9c323ec36b5cdb54eee803e17135f7abf9754171ee295fedf8844a46&req=19VswV76rzZk2hj99dpg6s71CyEwFqXHOh%2Bk26phmhqyukv2OEqOAc3x1zg0%0AAYHgaFE3l2SJFVEPaY0aOPEt%0A" alt="" style={{maxWidth: '100%', height: 'auto'}} />

### Contact enrichment

Configure: the column holding the contact's LinkedIn URL, your Lusha API key, which rows to enrich (all or only new/updated), which contact fields to populate, and whether to overwrite existing data.

### Company enrichment

Configure: the column holding the company name, your Lusha API key, which rows to enrich, which company fields to populate, and whether to overwrite existing data.

## Step 4: Connect your Lusha API key

When prompted, paste your Lusha API key. Your API key is available at [dashboard.lusha.com/enrich/api](https://dashboard.lusha.com/enrich/api) (visible to Admins and Managers only). The key is stored securely and only used for enrichment requests.

## Step 5: Start enriching

Once setup is complete, rows enrich automatically whenever the trigger fires — either a new row is added or a key column (LinkedIn URL or company name) is updated. You can also trigger enrichment manually by updating a row with the relevant identifier.

You're all set — your monday.com board will now stay enriched with verified Lusha data automatically.
