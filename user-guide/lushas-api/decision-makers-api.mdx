<Warning>
  **This endpoint has been retired.** Decision Makers has been superseded by [Buying Group](/user-guide/ai-recommendations/buying-group-find-the-right-contacts-fast), which covers the same use case with a broader persona set - Decision Maker, Champion, and End User, rather than decision makers only - plus per-contact relevance scoring.

  This article is kept for reference only. New integrations should use the Buying Group API.
</Warning>

Decision Makers identified and ranked the contacts most likely to close a deal at any given company. It has been retired and removed from the API reference as of September 4, 2026.

Use [Buying Group](/user-guide/ai-recommendations/buying-group-find-the-right-contacts-fast) instead - it covers the same use case with a broader persona set (Decision Maker, Champion, and End User) plus per-contact relevance scoring.
