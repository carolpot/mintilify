## June 8, 2026

### New: Decision Makers API

New endpoint `POST /v3/contacts/decision-makers` resolves a company to its most relevant contacts. Supply a company by domain or Lusha company ID and get back a ranked list of decision-maker contacts with name, title, location, and LinkedIn data.

## June 2, 2026

### New: Website Visits API

New endpoint `POST /v3/companies/website-visits` identifies companies visiting your tracked domains. Supports filtering by engagement score band (cold/warm/hot), session metrics, and geography, with a maximum lookback of 3 months.

## March 10, 2026

### New: Signal sub-filters and company lookalikes V3

Added an optional `signalsFilters` parameter to bulk company enrichment and the signals APIs. Launched `POST /v3/companies/lookalike` and a webhooks opt-out subscription feature.

<Note>
  In Contact Lookalikes V3, the result field `id` was renamed to `contactId`.
</Note>

## February 26, 2026

### New: Contact Lookalikes V3 and signal rate control

`POST /v3/lookalike/contacts` replaces `/api/recommendations/contacts` and supports multiple seed types. All four signals endpoints now require a `maxResultsPerSignal` parameter to control response size.

## February 18, 2026

### New: Company data points and expanded news signals

Added 7 new company fields, including `linkedinFollowers` and a `companyLocations` array. Replaced the generic `newsEvent` signal category with 7 granular news signal types across the API and webhooks.

## January 26, 2026

### New: Webhooks API

Launched the webhooks system: subscription management endpoints, real-time signal notifications, HMAC-SHA256 signature verification, automatic retry with exponential backoff (up to 3 attempts), and 90–180 day audit log retention.

## January 5, 2026

### Updated: Prospecting signal filtering

Prospecting search endpoints now support signal-based filtering and a `startDate` parameter for time-based filtering. Responses include a `signalTypes` array per result.

## October 15, 2025

### New: Recommendations API

Introduced AI-powered recommendation endpoints for contacts and companies to help expand prospect lists. Later superseded by Lookalikes V3.

## September 30, 2025

### New: Free-text search

Added a `searchText` filter supporting natural-language queries across the contact and company prospecting APIs.

## September 10, 2025

### New: Signals API expansion

Added four new signals endpoints, plus a GET endpoint for available signal filter types. Added a `partialProfile` parameter for simplified contact profiles.

## May 12, 2026

### New: MCP server (beta)

<!-- VERIFY: The live docs.lusha.com/mcp-docs page now shows the MCP server as generally available (OAuth support for Claude/ChatGPT/Codex, 20+ tools), not "beta" — and this launch isn't listed on the live changelog. The Lusha MCP server is now in public beta. Connect Lusha data to Claude, Cursor, Windsurf, and any other MCP-compatible client. See the [MCP documentation](/mcp/overview) to get started.

### Fixed: API Reference endpoint badges

All API Reference pages now correctly display the HTTP method badge and interactive playground. Previously, enrichment, signal, lookalike, and webhook pages were missing the method indicator.

## May 1, 2026

### Updated: Bulk company endpoint path

The bulk company enrichment endpoint is now documented at its correct path, `POST /bulk/company/v2`. The OpenAPI spec previously listed this operation under `POST /v2/company`.

<Note>
  This was a documentation fix only — the API endpoint itself did not change.
</Note>
