## Overview
This guide walks through the process of setting up the automation from Zoho to Lusha's API and ensures contact enrichment happens seamlessly.

## Requirements
This workflow requires an active Zoho subscription with the necessary Flow function enabled, along with the inclusion of Lusha resources (such as an API token for the account and available bulk credits).

- A credit will be consumed only when a match is successfully found
- Lusha's API key can be found [here](https://dashboard.lusha.com/api/manage-api-keys) (visible only by Lusha admins or managers)

## What is Zoho Workflow?
For this example we are going to be using the scenario where when a new contact is created in Zoho and is missing an email address, the webhook triggers Lusha's API to automatically populate the email field using the contact's first name, last name, and company name.

## Steps:

### 1. Set Up a Webhook in Zoho CRM

#### First, Navigate to Zoho CRM Settings:
1. Go to your Zoho CRM account
2. Click on the gear icon to access the setup page and type "Webhooks"

![Zoho CRM Settings](https://downloads.intercomcdn.eu/i/o/yu27vhse/26972886/90239cf420278d8faad5a571dc1a/Screenshot+2024-09-23+at+3_09_15%E2%80%AFPM.png?expires=1750098600&signature=3b4134a4ddb8fffe87fa26fc8aed066520666c2620cc84b46f937407f06dbc98&req=0tNmwlrypDFk2hL085ZhoT3DuBbgt2%2B%2FvOQqHxxqYTlMTTEd1Cy78hpIwJ6a%0A7WmL8oxZs2Mo9Omb%0A)

#### Create a Webhook Trigger
1. Select **Configure Webhook**
2. Name the Webhook and choose the endpoint METHOD (GET for this example)
3. Set the Module (Contacts for this example)
4. Define the URL (Lusha's Person V2 for this example: `https://api.lusha.com/v2/person`)

The URL should point to your service that will handle the integration with Lusha's API. Check [Lusha's API documentation](https://www.lusha.com/docs/#introduction) for the full list of available endpoints and its methods.

![Webhook Configuration](https://downloads.intercomcdn.eu/i/o/yu27vhse/26972897/ab13895555f57e3d0f126b51853f/d054b65d-a849-4350-808e-a4523d4a2752.png?expires=1750098600&signature=01295a02a0c819042c7f3a0c9b0df866f330ade3b9f78caf8408f5997b0c4083&req=0tNmwlrypTBk2hL085ZhoYukbIuhTjhyrCf8Zgb2KBKC8dC61yS%2FD6bCjKE1%0AXBogdShs%2FsZKDp3K%0A)

### 2. Create Connection:
1. Click **New connection > Custom Services > Create New service**
2. Name the service. The important here is to choose the Authentication type > **"API key"** and Parameter type > **"Header"**

![Connection Setup1](https://downloads.intercomcdn.eu/i/o/yu27vhse/26972908/95950d365769abb279d47b8437b4/465d140b-5b0c-46f2-968f-7d29b54a2e3b.png?expires=1750098600&signature=a00209fc5b4780d240c47ec6af9942968ba54dc421f1deac1faadf2e13659e9d&req=0tNmwlrzrD9k2hL085ZhoY3gyDxO0ssZnFM%2Bbw%2BsPdeVwChZ5wGTv%2BZqXANb%0ADO04RkrtldDIzcPO%0A)

3. Enter API key when requested. You can retrieve your API key [from here](https://dashboard.lusha.com/api/manage-api-keys) (only available to Lusha admins/managers)

![Connection Setup](https://downloads.intercomcdn.eu/i/o/yu27vhse/26972916/d9f41a7f3051e8ec9e01f1a1f6b8/482779b0-3f9b-496d-b1cf-80e601b7e633.png?expires=1750098600&signature=81c1f7bf1e770c65144bcfb63c66a0729af16d6e1f45248ee2d05bcdacbcd23e&req=0tNmwlrzrTFk2hL085ZhoWfpwwC6whvPhFHEmbX5AuWQEMQF1JKxQpdNyieg%0ASYZnbZjuznJcqZjj%0A)

Now that the connection is established let's go back to the Webhook creation and add the Parameters.

For this example, we will be using First Name, Last Name, and Company Name:

### 4. Create a Rule
1. Select the module (contacts for this example), name the rule, and click on next

Next step is setting up the condition for the rule to run. For this workflow we are using the "Record action" > "Create", meaning every time a record is being created (and it follows the conditions in which we will be using contacts with no emails) the rule will be executed.

![Rule Conditions](https://downloads.intercomcdn.eu/i/o/yu27vhse/26972931/789ce649ee8628b2cc53f5156682/c488ca6d-7869-4dac-8872-a9a34ac63e25.png?expires=1750098600&signature=6ee401874092940ed14c507435624587e9ee92156ba2d1923263bfe316c7aa4a&req=0tNmwlrzrzZk2hL085ZhoTz16cuOl2sHBD%2BS2QZewYEkhu3BZe51Z%2BhNRuDI%0AZmT%2BX5nCfWutwaut%0A)

2. After the Webhook that was initially created needs to be added to the flow (as an Action) and then the timing for this action to run.

![Rule Actions](https://downloads.intercomcdn.eu/i/o/yu27vhse/26972936/9e1626aef895f10b8774cc4b4cf5/c3ec4b9f-2291-4e78-b550-2bd5c5a420de.png?expires=1750098600&signature=6c7673306e2f0181265b9eae9f15c710ce4f4030f0116aa60c17db16e345fff1&req=0tNmwlrzrzFk2hL085ZhoX1nCJoJ0IY%2BbqVorntuE6RQB4SWBivMn0UqPOm%2F%0Aw4RHy7mdeH7HW2As%0A)

#### The flow is now finished 🔥

## Key Considerations

- **Authentication**: Ensure both Zoho and Lusha API calls are authenticated. Zoho requires OAuth tokens, while Lusha uses API keys
- **Rate Limits**: Be mindful of API rate limits for both Zoho and Lusha
- **Error Handling**: Implement error handling to manage cases where Lusha cannot find a matching email
