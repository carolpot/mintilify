The **Lusha MCP server** implements the [Model Context Protocol](https://modelcontextprotocol.io/) - a standard that lets AI assistants and agents call external tools directly. It's generally available today at `https://mcp.lusha.com`. Once connected, an MCP-compatible client can enrich contacts, search for prospects, and retrieve company data using natural language - without you writing a single API call.

<Note>
  The Lusha MCP server has moved beyond its original beta. Some connection details below (client list, exact tool set) can change as Lusha adds tools - always check the tools menu in your client for the current list.
</Note>

<Tip>
  **Starter prompt included.** Every new Lusha MCP connection ships with a built-in starter prompt on the client's consent screen - copy it in one click to run a real first query (find a person, verify they still work there, and pull their title and verified contact details) as soon as you connect. This is available across every MCP client below, not just Claude.
</Tip>

## What you can do with Lusha MCP

- Ask an AI assistant to "enrich this contact" and get back verified emails and phone numbers
- Instruct an agent to "find 20 VP of Engineering contacts at Series B companies in New York"
- Find companies or contacts that look like your best customers (lookalikes)
- Check recent hiring, headcount, or news signals for an account before you reach out
- Trigger a prospect list build from inside a Claude, ChatGPT, Cursor, or Gemini CLI session

The MCP server translates natural-language tool calls into authenticated Lusha API requests and returns structured results that the AI can reason over or pass downstream. Two connection methods are supported:

<CardGroup cols={2}>
  <Card title="OAuth" icon="key">
    For **Claude**, **ChatGPT**, and **Codex** - connect your Lusha account through the client's own connector directory. No API key handling required on your side.
  </Card>
  <Card title="API key" icon="lock">
    For **VS Code** (GitHub Copilot), **Cursor**, **Gemini CLI**, **n8n**, and any other MCP client - pass your key via an `x-api-key` header.
  </Card>
</CardGroup>

MCP tool calls use the same Lusha API key and credit pool as the REST API - see [MCP setup](/mcp/setup) for connecting each client.
