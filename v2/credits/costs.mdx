---
title: "Credit costs by endpoint"
description: "How many credits each Lusha API endpoint consumes per successful result."
---

Contact enrichment is charged **per data point revealed**, not a single flat rate. See [credits and plans](/v2/credits/overview) for the full breakdown of the email/phone/company data point costs. Company enrichment stays a flat 1 credit per matched company.

{/* VERIFY: could not confirm on live site whether bulk requests (POST /v2/person, POST /bulk/company/v2) are charged strictly per-result or in tiers of up to 25 results per credit — the "bulk" rows below assume per-result charging as the conservative baseline */}

| Endpoint | Credits per result |
|---|---|
| `GET /v2/person` | Minimum 1 credit per request, plus 1 credit if an email is revealed and 5 credits if a phone number is revealed (up to 7 total for both) |
| `POST /v2/person` (bulk) | Same per-contact cost as `GET /v2/person`, charged per matched contact |
| `GET /v2/company` | 1 credit per matched company |
| `POST /bulk/company/v2` | 1 credit per matched company |
| `POST /prospecting/contact/search` | No charge, unless you filter by signal type — credits are charged per signal type that returns results |
| `POST /prospecting/contact/enrich` | Same per-data-point cost as `GET /v2/person`; supports `revealEmails`/`revealPhones` on the Unified Credits plan |
| `POST /prospecting/company/search` | No charge, unless you filter by signal type — credits are charged per signal type that returns results |
| `POST /prospecting/company/enrich` | 1 credit per matched company |
| Signals (`/api/signals/*`) | 1 credit per signal type returned — for example, Job Change (per contact), Growth Surge in Hiring (per company), and Growth in Headcount (per company) |
| Lookalikes (`/v3/lookalike/*`) | 1 per profile returned |
| Webhooks (`/api/subscriptions`) | 1 credit per signal delivered, charged once per signal type — retried deliveries aren't charged again |
| Filters (`/prospecting/filters/*`, `/api/signals/filters/*`) | No charge |
| `GET /account/usage` | No charge |
