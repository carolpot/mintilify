The `/v3/lookalike/companies` endpoint returns new company prospects that share firmographic characteristics with your seed companies. Lusha's AI matches on industry, size, and other company attributes to surface accounts you haven't targeted yet.

{/* VERIFY: live site page (docs.lusha.com/apis/openapi/lookalikes/getcompanylookalikes) describes this endpoint as POST /v3/companies/lookalike, but openapi.json defines the path as POST /v3/lookalike/companies. This page follows openapi.json since it is the source the Mintlify API playground binds to; a human should confirm which path is actually live. */}

**Endpoint:** `POST https://api.lusha.com/v3/lookalike/companies`

**Authentication:** `api_key` header required

## How deduplication sessions work

Omit `dedupeSessionId` on your first request — the server generates one and returns it. Include the returned value in all subsequent calls to get more results without seeing the same companies twice. Sessions are retained for 30 days from last activity (sliding window).

## Request body

<ParamField body="seeds" type="object" required>
  Seed companies to match against. Provide at least one of `domains` or `linkedinUrls`. Across both arrays combined, provide 5–100 unique identifiers.

  <Expandable title="seeds fields">
    <ParamField body="seeds.domains" type="string[]">
      Company domains. Maximum 100 items. Example: `"sap.com"`
    </ParamField>

    <ParamField body="seeds.linkedinUrls" type="string[]">
      LinkedIn company URLs. Maximum 100 items. Example: `"https://www.linkedin.com/company/sap"`
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="dedupeSessionId" type="string">
  Session ID from a previous response. Omit on the first call; include on all subsequent "get more" calls.
</ParamField>

<ParamField body="exclude" type="object">
  Companies to exclude from results, in the same shape as `seeds` (`domains`, `linkedinUrls`).
</ParamField>

<ParamField body="limit" type="integer" default="25">
  Number of results to return per call. Accepted range: `1`–`100`.
</ParamField>

## Request examples

<CodeGroup>

```bash First request
curl --request POST \
  --url https://api.lusha.com/v3/lookalike/companies \
  --header 'api_key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "seeds": {
      "domains": ["sap.com", "oracle.com", "the-company.com"],
      "linkedinUrls": [
        "https://www.linkedin.com/company/google",
        "https://www.linkedin.com/company/someone"
      ]
    },
    "exclude": {
      "domains": ["existingcustomer.com", "already-sent.com"],
      "linkedinUrls": ["https://www.linkedin.com/company/already-sent/"]
    },
    "limit": 100
  }'
```

```bash Get more (subsequent request)
curl --request POST \
  --url https://api.lusha.com/v3/lookalike/companies \
  --header 'api_key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "dedupeSessionId": "58adaa77-7a6e-4c9b-8c2d-820a6538e613",
    "seeds": {
      "domains": ["sap.com", "oracle.com", "the-company.com"],
      "linkedinUrls": [
        "https://www.linkedin.com/company/google",
        "https://www.linkedin.com/company/someone"
      ]
    },
    "limit": 100
  }'
```

</CodeGroup>

## Response

### 200 — Success

<ResponseField name="dedupeSessionId" type="string">
  Server-generated session ID to use for subsequent "get more" requests.
</ResponseField>

<ResponseField name="results" type="object[]">
  Array of lookalike companies.

  <Expandable title="properties">
    <ResponseField name="domain" type="string">
      Company domain. Example: `"marriott.com"`
    </ResponseField>

    <ResponseField name="linkedinUrl" type="string">
      LinkedIn company URL.
    </ResponseField>

    <ResponseField name="name" type="string">
      Company name.
    </ResponseField>

    <ResponseField name="employeeCount" type="integer">
      Best-available employee count.
    </ResponseField>

    <ResponseField name="industry" type="string">
      Industry name or category.
    </ResponseField>

    <ResponseField name="location" type="object">
      `country`, `state`, and `city` for the company.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="meta" type="object">
  `returned` (number of results in this response) and `hasMore` (whether more results are available for the same seeds and `dedupeSessionId`).
</ResponseField>

<ResponseField name="creditsCharged" type="integer">
  Number of credits charged for this request.
</ResponseField>

## Error responses

| Status | Meaning |
|--------|---------|
| `400` | Invalid request body or missing required fields |
| `401` | Missing or invalid API key |
| `402` | Insufficient credits |
| `403` | Account inactive or feature not available on your plan |
| `410` | `dedupeSessionId` is invalid or expired — start a new run by omitting it |
| `500` | Internal server error |

```json 410
{
  "statusCode": 410,
  "errors": ["DEDUPE_SESSION_INVALID"],
  "message": "The provided dedupeSessionId is invalid or expired. Generate a new request without dedupeSessionId to start a fresh run."
}
```
