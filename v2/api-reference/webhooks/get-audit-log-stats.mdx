Retrieve aggregated delivery statistics for your account. Instead of paging through individual log entries, this endpoint gives you a high-level view of overall webhook health — including total delivery counts, success and failure rates, and trends over time. Use it to detect elevated failure rates early, before subscriptions are auto-disabled.

**Endpoint:** `GET https://api.lusha.com/api/audit-logs/stats`

## Query parameters

<ParamField query="subscriptionId" type="string">
  Filter statistics to a single subscription. Omit to get account-wide statistics.
</ParamField>

## Example request

```bash
curl --request GET \
  --url https://api.lusha.com/api/audit-logs/stats \
  --header 'api_key: YOUR_API_KEY'
```

## Example response

```json
{
  "total": 1000,
  "success": 950,
  "failed": 50,
  "successRate": "95.00%"
}
```

## Response fields

<ResponseField name="total" type="integer">
  Total number of delivery attempts recorded.
</ResponseField>

<ResponseField name="success" type="integer">
  Number of deliveries where your endpoint responded with an HTTP `2xx` within 10 seconds.
</ResponseField>

<ResponseField name="failed" type="integer">
  Number of deliveries that failed due to a non-`2xx` response or timeout.
</ResponseField>

<ResponseField name="successRate" type="string">
  Success rate expressed as a percentage string, for example `"95.00%"`.
</ResponseField>

<Tip>
  Monitor this endpoint regularly to catch elevated failure rates early, before subscriptions are automatically disabled. A declining success rate is a signal to check your endpoint health and review recent [audit log entries](/v2/api-reference/webhooks/get-audit-logs).
</Tip>
