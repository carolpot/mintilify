Retrieve the list of available company size ranges for filtering companies by headcount in `POST /prospecting/company/search`. Each range is a `{min, max}` object representing a headcount band. Use the exact objects returned by this endpoint in your search request.

**Endpoint:** `GET https://api.lusha.com/prospecting/filters/companies/sizes`

## Example request

```bash
curl --request GET \
  --url https://api.lusha.com/prospecting/filters/companies/sizes \
  --header 'api_key: YOUR_API_KEY'
```

## Example response

```json
[
  { "min": 1, "max": 10 },
  { "min": 11, "max": 50 },
  { "min": 51, "max": 200 }
]
```

## Usage

Pass one or more `{min, max}` objects from the response into the `sizes` filter field of your company search request:

```json
{
  "sizes": [
    { "min": 51, "max": 200 },
    { "min": 201, "max": 500 }
  ]
}
```

<Tip>
  Cache the response from this endpoint. Size ranges are stable and do not change frequently.
</Tip>
