Search for company names by free-text query to use in the `names` filter field of `POST /prospecting/company/search`. The endpoint returns matching companies with their `companyId`, `name`, `logoUrl`, and `fqdn` as recognized by the Lusha database. Use the exact `name` values returned here to target specific companies in your prospecting searches.

**Endpoint:** `POST https://api.lusha.com/prospecting/filters/companies/names`

## Request body

<ParamField body="text" type="string" required>
  Free-text search string to match against company names. For example, `"Salesforce"` or `"Lusha"`.
</ParamField>

## Example request

```bash
curl --request POST \
  --url https://api.lusha.com/prospecting/filters/companies/names \
  --header 'api_key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{ "text": "Lusha" }'
```

## Example response

```json
[
  {
    "companyId": 33222678,
    "name": "Lusha",
    "logoUrl": "https://logo.lusha.co/d/company_33222678_logo.jpg",
    "fqdn": "www.lusha.com"
  }
]
```

## Usage

Pass the `name` values returned by this endpoint into the `names` filter field of your company search request:

```json
{
  "names": ["Lusha"]
}
```
