Search for location values by free-text query to use in the `locations` filter field of `POST /prospecting/company/search`. This endpoint returns matching country-level location objects — with `country`, `continent`, and `country_grouping` — as recognized by the Lusha database. This filters by a company's HQ location only. Use the exact objects returned here in your search request to ensure results are returned correctly.

**Endpoint:** `POST https://api.lusha.com/prospecting/filters/companies/locations`

## Request body

<ParamField body="text" type="string" required>
  Free-text search string to match against location names. For example, `"Austin"` or `"San Francisco"`.
</ParamField>

## Example request

```bash
curl --request POST \
  --url https://api.lusha.com/prospecting/filters/companies/locations \
  --header 'api_key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{ "text": "Austin" }'
```

## Example response

```json
[
  {
    "country": "United States",
    "continent": "North America",
    "country_grouping": "na"
  }
]
```

## Usage

Pick the location object that matches your target area and pass it into the `locations` filter field of your company search request:

```json
{
  "locations": [{ "country": "United States" }]
}
```

<Note>
  `locations` matches HQ location only. To filter by site-level office locations instead — which supports `country` and `state` — use the separate `companyLocations` filter field.
</Note>
