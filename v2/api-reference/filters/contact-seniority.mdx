Retrieve the list of valid seniority levels for filtering contacts in `POST /prospecting/contact/search`. Seniority levels range from entry-level individual contributors to C-suite executives. Each level is returned as an `{id, name}` object, and contacts are filtered by the numeric `id`, not by the name string.

**Endpoint:** `GET https://api.lusha.com/prospecting/filters/contacts/seniority`

## Example request

```bash
curl --request GET \
  --url https://api.lusha.com/prospecting/filters/contacts/seniority \
  --header 'api_key: YOUR_API_KEY'
```

## Example response

```json
[
  { "id": 10, "name": "founder" },
  { "id": 9, "name": "c-suite" },
  { "id": 8, "name": "vice president" }
]
```

## Usage

Pass one or more `id` values from the response into the `seniority` filter field of your contact search request:

```json
{
  "seniority": [10, 9, 8]
}
```

<Tip>
  Cache the response from this endpoint. Seniority values rarely change and do not need to be fetched on every search run.
</Tip>
