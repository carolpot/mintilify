Retrieve the list of available annual revenue ranges for filtering companies in `POST /prospecting/company/search`. Use these ranges to target companies by their reported annual revenue band. Always use the exact `{min, max}` objects returned by this endpoint to ensure your filters are applied correctly.

**Endpoint:** `GET https://api.lusha.com/prospecting/filters/companies/revenues`

## Example request

```bash
curl --request GET \
  --url https://api.lusha.com/prospecting/filters/companies/revenues \
  --header 'api_key: YOUR_API_KEY'
```

## Example response

```json
[
  { "min": 1, "max": 1000000 },
  { "min": 1000001, "max": 10000000 }
]
```

Each range is a raw USD `{min, max}` pair, not a formatted string.

## Usage

Pass one or more `{min, max}` objects from the response into the `revenues` filter field of your company search request:

```json
{
  "revenues": [{ "min": 1000001, "max": 10000000 }]
}
```

<Tip>
  Cache the response from this endpoint. Revenue range values are stable and rarely change.
</Tip>
