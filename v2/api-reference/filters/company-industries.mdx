Retrieve the industry hierarchy you can use to filter companies in `POST /prospecting/company/search`. Companies are filtered by numeric industry ID, not by label string — use the `main_industry_id` and `sub_industries[].id` values returned by this endpoint.

**Endpoint:** `GET https://api.lusha.com/prospecting/filters/companies/industries_labels`

## Example request

```bash
curl --request GET \
  --url https://api.lusha.com/prospecting/filters/companies/industries_labels \
  --header 'api_key: YOUR_API_KEY'
```

## Example response

```json
[
  {
    "main_industry": "Hospitality",
    "main_industry_id": 1,
    "sub_industries": [{ "value": "Other", "id": 778 }]
  }
]
```

## Usage

There's no `industries` string filter field. Instead, pass `main_industry_id` values into `mainIndustriesIds`, and any `sub_industries[].id` values into `subIndustriesIds`, in your company search request:

```json
{
  "mainIndustriesIds": [1],
  "subIndustriesIds": [778]
}
```

<Tip>
  Cache the response from this endpoint. Industry values change infrequently.
</Tip>
