---
title: "Enrich prospecting companies with full company data"
sidebarTitle: "Enrich Companies"
description: "Turn company IDs from a prospecting search into full records — firmographics, headcount, revenue, technologies, locations, and more."
---

`POST https://api.lusha.com/prospecting/company/enrich` is step 3 of the 3-step company prospecting flow. You pass the `requestId` returned by [Search Companies](/v2/prospecting/search-companies) along with the company `id` values you want to enrich, and receive back complete company records with firmographics, headcount, revenue estimates, technology stack, and signal data. Credits are charged at this step for each company successfully enriched.

## Request body

Send a JSON body with the `requestId` from your search response and an array of company IDs to enrich, under `companiesIds`. You can enrich up to 100 companies per request.

```json
{
  "requestId": "5ad275c8-7dd4-462a-bd45-6bc1970da64e",
  "companiesIds": ["33222678", "1586"]
}
```

### Request fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `requestId` | string | Yes | The `requestId` returned by `/prospecting/company/search` for the same session |
| `companiesIds` | string[] | Yes | Company `id` values from the search results. Minimum 1, maximum 100 |

## Example request

<CodeGroup>

```bash cURL
curl --request POST \
  --url https://api.lusha.com/prospecting/company/enrich \
  --header 'api_key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "requestId": "5ad275c8-7dd4-462a-bd45-6bc1970da64e",
    "companiesIds": ["33222678", "1586"]
  }'
```

```json Request body
{
  "requestId": "5ad275c8-7dd4-462a-bd45-6bc1970da64e",
  "companiesIds": ["33222678", "1586"]
}
```

</CodeGroup>

### Response fields

| Field | Description |
|-------|-------------|
| `id` | Lusha's unique company identifier |
| `name` | Company name |
| `fqdn` | Primary domain |
| `description` | Short company description |
| `companySize` | Employee count range as `{ min, max, employees_in_linkedin }` |
| `employees` | Formatted employee range string, e.g. `"201 - 500"` |
| `revenueRange` | Revenue range in USD as `[min, max]` |
| `mainIndustry` / `subIndustry` | Industry classification |
| `city` / `state` / `country` / `countryIso2` / `continent` | HQ location (flat fields, not nested) |
| `companyLocations` | All known office locations, not just HQ |
| `technologies` | Technologies detected in use |
| `funding` / `intent` | Funding history and buyer intent data |
| `surgeInHiring`, `headcountIncrease1m`, `websiteTrafficIncrease`, etc. | Signal fields — present only for companies matching a requested signal type |

See the [full API reference](/v2/api-reference/prospecting/enrich-companies) for the complete response schema, including all available signal fields.

<Tip>
  Enrich in batches of up to 100 IDs per request. Store the `requestId` and remaining company IDs and enrich them on demand as accounts are needed in your CRM or sales workflow.
</Tip>
