Website Visits turns anonymous website traffic into a ranked list of companies. Give it your tracked domains and a date range, and it returns the companies that visited, ranked by engagement — score, total sessions, unique visitors, days visited, high-intent pageviews, and more.

## Prerequisite: configure domain tracking

Website Visits only returns data for domains you've already set up for tracking in the [Lusha dashboard](https://dashboard.lusha.com). The API resolves each domain you pass to its tracked site ID server-side — it doesn't scan arbitrary websites.

<Warning>
  If any domain in your request isn't configured for tracking, the entire request fails with `400`. Set up tracking for a domain in the dashboard before calling this endpoint with it.
</Warning>

## Date range limit

`startDate` and `endDate` must together span **3 months or less**. Request a range longer than that and the call fails with `400`. To cover a longer period, make multiple calls with adjacent date ranges.

## What you get back

Each result combines a company firmographic preview — the same shape [Search Companies](/enrichment/search-companies) returns (name, domain, industry, location, employee count) — with visit-behavior metrics:

| Metric | Description |
|---|---|
| `score` | Overall engagement score |
| `scoreBand` | `cold`, `warm`, or `hot` |
| `totalSessions` | Total sessions in the date range |
| `uniqueVisitors` | Unique visitors in the date range |
| `avgSessionMinutes` | Average session duration |
| `daysVisited` | Distinct days with at least one visit |
| `highIntentPageviews` | Pageviews on high-intent pages |
| `daysSinceLastVisit` | Days since the most recent visit |
| `lastVisit` | Date of the most recent visit |
| `visitorCountry` | Country the visit traffic came from |

## Filtering and sorting

Narrow results with `filters` — by `scoreBands`, visitor country (`visitorCountries.include` / `.exclude`), or range filters (`score`, `totalSessions`, `uniqueVisitors`, `daysVisited`, `highIntentPageviews`, `daysSinceLastVisit`, `avgSessionMinutes`). Sort with `sort.by` / `sort.order` (for example, sort by `score` descending to see your hottest accounts first).

<Tip>
  Combine `scoreBands: ["hot"]` with a recent date range to build a "companies to contact this week" list, then pass the matched domains into [Decision Makers](/decision-makers/overview) to find who to reach out to.
</Tip>
