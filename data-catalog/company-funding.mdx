---
title: "Company funding fields"
description: "Funding rounds, total raised, last round details, and IPO status."
---

Funding data summarizes a company's fundraising history. It's returned in the `funding` object as part of the company record by [Enrich Companies](/enrichment/enrich-companies) and [Search and Enrich Companies](/enrichment/search-and-enrich-companies).

<!-- VERIFY: field names below were derived from the legacy V2 API schema — re-verify against V3EnrichedCompany.funding in openapi.json. -->

## `funding` summary fields

| Field | Type | Description |
|---|---|---|
| `totalRounds` | number | Total number of funding rounds on record. |
| `totalRoundsAmount` | number | Total amount raised across all rounds. |
| `currency` | string | Currency of the amounts in this object, for example `"USD"`. |
| `isIpo` | boolean | Whether the company has gone public. |
| `lastRoundType` | string | The type of the most recent funding round, for example `"Private Equity Round"` or `"Series A"`. This is the closest signal to a growth stage that the API exposes. |
| `lastRoundAmount` | number | Amount raised in the most recent round. |
| `lastRoundDate` | string | Date of the most recent round, for example `"Nov 10, 2021"`. |
| `rounds` | array | The individual funding rounds — see below. |

## `funding.rounds[]`

Each entry in `rounds` describes a single funding round.

| Field | Type | Description |
|---|---|---|
| `currency` | string | Currency of the round amount. |
| `roundAmount` | number | Amount raised in this round. |
| `roundType` | string | Type of round, for example `"Series A"` or `"Private Equity Round"`. |
| `roundDate` | string | Date of the round. |

```json
{
  "funding": {
    "totalRounds": 2,
    "totalRoundsAmount": 245000000,
    "currency": "USD",
    "isIpo": false,
    "lastRoundType": "Private Equity Round",
    "lastRoundAmount": 205000000,
    "lastRoundDate": "Nov 10, 2021",
    "rounds": [
      {
        "currency": "USD",
        "roundAmount": 205000000,
        "roundType": "Private Equity Round",
        "roundDate": "Nov 10, 2021"
      }
    ]
  }
}
```

<Note>
  Funding rounds don't include individual investor names — only aggregate round-level data (amount, type, date, currency) and the running totals above.
</Note>
