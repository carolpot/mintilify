title: "Company technology fields"

---

Technology data identifies the software, platforms, and tools a company runs. It's returned as part of the company record by [`GET /v2/company`](/enrichment/single-company), [`POST /bulk/company/v2`](/enrichment/bulk-companies), and [`POST /prospecting/company/enrich`](/prospecting/enrich-companies).

## `technologies`

`technologies` is an array of objects, one per detected technology.

| Field | Type | Description |
|---|---|---|
| `name` | string | The name of the technology the company uses, for example `"salesforce"`. |

```json
{
  "technologies": [
    { "name": "salesforce" },
    { "name": "aws" },
    { "name": "hubspot" }
  ]
}
```

<Note>
  The schema for a technology entry is a single `name` field — there's no separate category, vendor, or first-detected-date field returned alongside it.
</Note>

## Filtering and searching by technology

To find companies that use a specific technology, or to validate technology names before filtering:

- Use [`POST /prospecting/filters/companies/technologies`](/api-reference/filters/company-technologies) to search for valid technology name values by free text.
- Pass matching values into the `technologies` filter field of [`POST /prospecting/company/search`](/prospecting/search-companies).
