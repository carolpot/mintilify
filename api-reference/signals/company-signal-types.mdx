Call this endpoint to get the current, authoritative list of `signalTypes` values accepted by [Company Signals](/api-reference/signals/company-signals). Use it instead of hardcoding signal type strings, so your integration picks up new types automatically as Lusha adds them.

## Endpoint

```
GET https://api.lusha.com/v3/companies/signals/types
```

**Authentication:** API key (`ApiKeyAuth`)

This endpoint has no parameters.

---

## Example request

```bash cURL
curl --request GET \
  --url https://api.lusha.com/v3/companies/signals/types \
  --header 'api_key: YOUR_API_KEY'
```

---
