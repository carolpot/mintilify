Call this endpoint to get the current, authoritative list of `signalTypes` values accepted by [Contact Signals](/api-reference/signals/contact-signals). Use it instead of hardcoding signal type strings, so your integration picks up new types automatically as Lusha adds them.

## Endpoint

```
GET https://api.lusha.com/v3/contacts/signals/types
```

**Authentication:** API key (`ApiKeyAuth`)

This endpoint has no parameters.

---

## Example request

```bash cURL
curl --request GET \
  --url https://api.lusha.com/v3/contacts/signals/types \
  --header 'api_key: YOUR_API_KEY'
```

---

## Response

### 200 — Success

<ResponseField name="signalTypes" type="string[]">
  All valid `signalTypes` values for [Contact Signals](/api-reference/signals/contact-signals).
</ResponseField>

<ResponseExample>

```json 200
{
  "signalTypes": [
    "allSignals",
    "promotion",
    "companyChange"
  ]
}
```

</ResponseExample>
