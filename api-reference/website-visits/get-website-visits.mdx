<Warning>
  **Beta.** This endpoint's request and response shape may change before general availability.
</Warning>

Returns companies ranked by website-visit behavior for the tracked domains and date range you supply. Each result combines a V3 company firmographic preview - the same shape [Search Companies](/enrichment/search-companies) returns - with behavioral visit metrics: engagement score, sessions, unique visitors, and more.

<Warning>
  Domains must already be configured for tracking in the [Lusha dashboard](https://dashboard.lusha.com) - they're resolved to site IDs server-side. If any requested domain isn't configured for tracking, the entire request fails with `400`.
</Warning>

## Endpoint

```
POST https://api.lusha.com/v3/companies/website-visits
```

**Authentication:** API key (`ApiKeyAuth`)

---

## Request body

<ParamField body="domains" type="string[]" required>
  Tracked domains to pull visit data for. At least 1 item.

  Example: `["lusha.com", "google.com"]`
</ParamField>

<ParamField body="startDate" type="string" required>
  Start of the date range, in `YYYY-MM-DD` format.

  Example: `"2026-01-01"`
</ParamField>

<ParamField body="endDate" type="string" required>
  End of the date range, in `YYYY-MM-DD` format.

  Example: `"2026-03-18"`
</ParamField>

<Warning>
  The `startDate`–`endDate` range must be 3 months or less.
</Warning>

<ParamField body="pagination" type="object" required>
  <Expandable title="pagination fields">
    <ParamField body="pagination.page" type="integer" required>
      Zero-indexed page number.

      Example: `0`
    </ParamField>
    <ParamField body="pagination.size" type="integer" required>
      Results per page. Range: `1`–`150`.

      Example: `25`
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="sort" type="object">
  <Expandable title="sort fields">
    <ParamField body="sort.by" type="string">
      Field to sort results by.

      Example: `"score"`
    </ParamField>
    <ParamField body="sort.order" type="string">
      Sort direction.

      Allowed values: `asc`, `desc`
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="filters" type="object">
  Optional filters to narrow results.

  <Expandable title="filters fields">
    <ParamField body="filters.scoreBands" type="string[]">
      Restrict results to companies in these engagement bands.

      Allowed values: `cold`, `warm`, `hot`
    </ParamField>
    <ParamField body="filters.visitorCountries" type="object">
      <Expandable title="properties">
        <ParamField body="filters.visitorCountries.include" type="string[]">ISO country codes to include. Example: `["US", "GB"]`</ParamField>
        <ParamField body="filters.visitorCountries.exclude" type="string[]">ISO country codes to exclude. Example: `["CN"]`</ParamField>
      </Expandable>
    </ParamField>
    <ParamField body="filters.score" type="object">
      Integer range filter, `{ "min": 0, "max": 100 }`. Both bounds optional.
    </ParamField>
    <ParamField body="filters.totalSessions" type="object">
      Integer range filter on total sessions.
    </ParamField>
    <ParamField body="filters.uniqueVisitors" type="object">
      Integer range filter on unique visitor count.
    </ParamField>
    <ParamField body="filters.daysVisited" type="object">
      Integer range filter on distinct days visited.
    </ParamField>
    <ParamField body="filters.highIntentPageviews" type="object">
      Integer range filter on high-intent pageviews.
    </ParamField>
    <ParamField body="filters.daysSinceLastVisit" type="object">
      Integer range filter on days since the last visit.
    </ParamField>
    <ParamField body="filters.avgSessionMinutes" type="object">
      Float range filter (`{ "min": ..., "max": ... }`) on average session duration in minutes.
    </ParamField>
  </Expandable>
</ParamField>

## Example request

<CodeGroup>

```bash cURL
curl --request POST \
  --url https://api.lusha.com/v3/companies/website-visits \
  --header 'api_key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "domains": ["lusha.com", "google.com"],
    "startDate": "2026-01-01",
    "endDate": "2026-03-18",
    "pagination": { "size": 25, "page": 0 },
    "sort": { "by": "score", "order": "desc" },
    "filters": {
      "scoreBands": ["hot", "warm"],
      "score": { "min": 50 }
    }
  }'
```

## Error codes

| Status | Meaning |
|--------|---------|
| `400` | Bad request - invalid input, a domain isn't configured for tracking, or the date range exceeds 3 months. |
| `401` | Unauthorized - your API key is missing or invalid. |
| `402` | Payment required - insufficient credits. |
| `403` | Forbidden - account inactive or V3 access not enabled. |
| `429` | Too many requests - you have exceeded the rate limit. |
