Permanently delete one or more webhook subscriptions in a single request. Each subscription is processed independently and the response includes a detailed result for every item, making it easy to confirm which deletions succeeded and which did not.

**Endpoint:** `POST https://api.lusha.com/api/subscriptions/delete`

<Warning>
  Deletion is permanent and cannot be undone. Deleted subscriptions stop receiving deliveries immediately.
</Warning>

<Note>
  You can delete up to 25 subscriptions per request. Duplicate IDs in the same request are automatically deduplicated.
</Note>

## Request body

<ParamField body="ids" type="string[]" required>
  Array of subscription IDs to delete. Maximum 25 items. Duplicates are deduplicated automatically.
</ParamField>

## Example request

```bash
curl --request POST \
  --url https://api.lusha.com/api/subscriptions/delete \
  --header 'api_key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "ids": [
      "507f1f77bcf86cd799439011",
      "507f1f77bcf86cd799439012"
    ]
  }'
```

## Example response

```json
{
  "total": 2,
  "successful": 1,
  "failed": 1,
  "results": [
    {
      "index": 0,
      "success": true,
      "subscription": {
        "id": "507f1f77bcf86cd799439011",
        "entityType": "contact",
        "entityId": "123",
        "name": "Contact Webhook"
      }
    },
    {
      "index": 1,
      "success": false,
      "error": {
        "code": "NOT_FOUND",
        "message": "Subscription with id '507f1f77bcf86cd799439012' not found"
      }
    }
  ]
}
```

## Response fields

<ResponseField name="total" type="integer">
  Total number of deletion attempts.
</ResponseField>

<ResponseField name="successful" type="integer">
  Number of subscriptions deleted successfully.
</ResponseField>

<ResponseField name="failed" type="integer">
  Number of deletion attempts that failed.
</ResponseField>

<ResponseField name="results" type="object[]">
  Per-item results, one entry for each ID in the request, in the same order.

  <Expandable title="properties">
    <ResponseField name="index" type="integer">
      Index of the ID in the request `ids` array.
    </ResponseField>

    <ResponseField name="success" type="boolean">
      Whether this deletion succeeded.
    </ResponseField>

    <ResponseField name="subscription" type="object">
      Information about the deleted subscription (`id`, `entityType`, `entityId`, `name`). Only present when `success` is `true`.
    </ResponseField>

    <ResponseField name="error" type="object">
      An error object with `code` and `message`, for example `NOT_FOUND` for an ID that doesn't match an existing subscription. Only present when `success` is `false`.
    </ResponseField>
  </Expandable>
</ResponseField>

## Behavior notes

- Each subscription is processed independently. A failure on one ID does not affect the others.
- Invalid ID formats are handled gracefully and reported as `NOT_FOUND` rather than causing the entire request to fail.
- Duplicate IDs are deduplicated before processing — you will not see duplicate entries in the response.
