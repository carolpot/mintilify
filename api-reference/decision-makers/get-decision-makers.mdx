<Warning>
  **Beta.** This endpoint's request and response shape may change before general availability.
</Warning>

Give this endpoint a list of companies — by `domain` or Lusha company `id` — and it resolves each one to a Lusha company record, ranks the most relevant decision makers per company using Lusha's buying-committee-ranker model, and returns them grouped per company.

Results are **free previews**: name, title, company, location, LinkedIn, seniority, and department, along with `has` and `canReveal` fields telling you what's available to unlock. Reveal emails and phone numbers separately with [Enrich Contacts](/enrichment/enrich-contacts) — this endpoint itself does not charge for contact detail reveals.

## Endpoint

```
POST https://api.lusha.com/v3/contacts/decision-makers
```

**Authentication:** API key (`ApiKeyAuth`)

---

## Request body

<ParamField body="companies" type="object[]" required>
  Companies to find decision makers for. At least 1 item.

  Each entry requires exactly one company identifier — `domain` or `id`:

  <Expandable title="companies[] fields">
    <ParamField body="companies[].domain" type="string">
      Company domain. Resolved to a Lusha company ID server-side.

      Example: `"google.com"`
    </ParamField>
    <ParamField body="companies[].id" type="string">
      Lusha company ID — encrypted format (`v1.…`) or legacy numeric ID (accepted during the migration window).

      Example: `"v1.AbCdEfGhIjKlMnOpQrStUvWxYz012345"`
    </ParamField>
    <ParamField body="companies[].clientReferenceId" type="string">
      Your own reference ID for this company. Echoed back on the matching result so you can join results back to your records.

      Example: `"ref-1"`
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="pagination" type="object">
  Pagination for the decision makers returned per company.

  <Expandable title="pagination fields">
    <ParamField body="pagination.page" type="integer" default="0">
      Zero-indexed page number.
    </ParamField>
    <ParamField body="pagination.size" type="integer" default="10">
      Results per page. Range: `1`–`100`.
    </ParamField>
  </Expandable>
</ParamField>

## Example request

<CodeGroup>

```bash cURL
curl --request POST \
  --url https://api.lusha.com/v3/contacts/decision-makers \
  --header 'api_key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "companies": [
      { "domain": "google.com", "clientReferenceId": "ref-1" },
      { "id": "v1.AbCdEfGhIjKlMnOpQrStUvWxYz012345" }
    ],
    "pagination": { "page": 0, "size": 10 }
  }'
```

## Response

### 200 — Success

<ResponseField name="requestId" type="string">
  UUID identifying this request. Useful when contacting support about a specific call.
</ResponseField>

<ResponseField name="results" type="object[]">
  One entry per requested company.

  <Expandable title="properties">
    <ResponseField name="clientReferenceId" type="string">
      Echoes the `clientReferenceId` you supplied for this company, if any. Example: `"ref-1"`
    </ResponseField>
    <ResponseField name="companyId" type="string">
      The resolved Lusha company ID. Example: `"v1.AbCdEfGhIjKlMnOpQrStUvWxYz012345"`
    </ResponseField>
    <ResponseField name="domain" type="string">
      The company's domain. Example: `"unknown-co.com"`
    </ResponseField>
    <ResponseField name="decisionMakers" type="object[]">
      Ranked decision-maker contact previews for this company.

      <Expandable title="properties">
        <ResponseField name="clientReferenceId" type="string">Your reference ID, if the contact itself was supplied with one (not applicable for most Decision Makers use — see `companies[].clientReferenceId` for the company-level reference).</ResponseField>
        <ResponseField name="id" type="string">Lusha contact ID. Example: `"4389064704"`</ResponseField>
        <ResponseField name="firstName" type="string">Example: `"Orit"`</ResponseField>
        <ResponseField name="lastName" type="string">Example: `"Shilvock"`</ResponseField>
        <ResponseField name="jobTitle" type="object">
          <Expandable title="properties">
            <ResponseField name="title" type="string">Example: `"Vice President of Partnerships"`</ResponseField>
            <ResponseField name="departments" type="string[]">Example: `["Business Development"]`</ResponseField>
            <ResponseField name="seniority" type="string">Example: `"Vice President"`</ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="company" type="object">
          <Expandable title="properties">
            <ResponseField name="id" type="string">Example: `"16303253"`</ResponseField>
            <ResponseField name="name" type="string">Example: `"Lusha"`</ResponseField>
            <ResponseField name="domain" type="string">Example: `"www.lusha.com"`</ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="location" type="object">
          <Expandable title="properties">
            <ResponseField name="country" type="string">Example: `"Israel"`</ResponseField>
            <ResponseField name="state" type="string">Example: `"Tel Aviv District"`</ResponseField>
            <ResponseField name="city" type="string">Example: `"Tel Aviv"`</ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="socialLinks" type="object">
          <Expandable title="properties">
            <ResponseField name="linkedin" type="string">Example: `"https://www.linkedin.com/in/orit-shilvock-6243bb5"`</ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="has" type="string[]">
          Fields already available on this preview without a reveal. Example: `["firstName", "lastName", "jobTitle", "location", "socialLinks", "emails"]`
        </ResponseField>
        <ResponseField name="canReveal" type="object[]">
          Fields you can reveal via [Enrich Contacts](/enrichment/enrich-contacts), and their credit cost.

          <Expandable title="properties">
            <ResponseField name="field" type="string">`"emails"` or `"phones"`</ResponseField>
            <ResponseField name="credits" type="integer">Credit cost to reveal this field. `0` if already revealed for your account. Example: `1`</ResponseField>
          </Expandable>
        </ResponseField>
        <ResponseField name="signalTypes" type="string[]">
          Signal types currently associated with this contact, if any. Example: `["promotion", "companyChange"]`
        </ResponseField>
        <ResponseField name="error" type="object">
          Present when this specific contact couldn't be resolved.

          <Expandable title="properties">
            <ResponseField name="code" type="string">One of `NOT_FOUND`, `COMPLIANCE_RESTRICTED`, `ENRICH_FAILED`.</ResponseField>
            <ResponseField name="message" type="string">Human-readable error description.</ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="error" type="object">
      Present when the company itself couldn't be resolved (same shape as the contact-level `error` above).
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="billing" type="object">

  </Expandable>
