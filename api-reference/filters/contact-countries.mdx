Retrieve the full list of countries available for contact location filtering, returned as `{name, code}` objects. There is no standalone `countries` filter field on `POST /prospecting/contact/search` — use a country `name` from this endpoint inside a `locations` entry (see `POST /prospecting/filters/contacts/locations`).

**Endpoint:** `GET https://api.lusha.com/prospecting/filters/contacts/all_countries`

## Example request

```bash
curl --request GET \
  --url https://api.lusha.com/prospecting/filters/contacts/all_countries \
  --header 'api_key: YOUR_API_KEY'
```

## Example response

```json
[
  { "name": "United States", "code": "US" },
  { "name": "United Kingdom", "code": "GB" }
]
```

## Usage

There's no standalone `countries` filter field. Instead, put the `name` value into a `locations` entry under `filters.contacts.include` in your contact search request:

```json
{
  "filters": {
    "contacts": {
      "include": {
        "locations": [{ "country": "United States" }]
      }
    }
  }
}
```

<Tip>
  Cache the response from this endpoint. The country list changes infrequently. For more granular location filtering — such as targeting specific cities or regions — use `POST /prospecting/filters/contacts/locations`.
</Tip>
