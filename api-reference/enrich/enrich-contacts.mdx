Use this endpoint to reveal full contact data for contacts you've already found via [Search Contacts](/api-reference/search/search-contacts). Pass the Lusha `id` from a search result, and choose what to unlock with `reveal`.

<Info>
  Enrich Contacts only works with `id` values returned by Search Contacts. It doesn't accept `email`, `linkedinUrl`, or name-based identifiers. To search and reveal in one call, use [Search and Enrich Contacts](/api-reference/search-and-enrich/search-and-enrich-contacts) instead.
</Info>

## Endpoint

```
POST https://api.lusha.com/v3/contacts/enrich
```

## Authentication

<ParamField header="api_key" type="string" required>
  Your Lusha API key.
</ParamField>

## Request body

<ParamField body="ids" type="string[]" required>
  Up to 100 Lusha contact IDs, from a Search Contacts response.

  Example: `["4389064654", "4389064624"]`
</ParamField>

<ParamField body="reveal" type="string[]">
  What to unlock for each contact. Omit this field to get both by default.

  Allowed values: `emails`, `phones`
</ParamField>

  **Billing:** Charged per revealed field (email or phone) via per-datapoint pricing.
</Info>
