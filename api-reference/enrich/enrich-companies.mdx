Use this endpoint to reveal full company data for companies you've already found via [Search Companies](/api-reference/search/search-companies). Pass the Lusha `id` from a search result. Every enriched result includes firmographics, industry codes, and locations by default; use `reveal` to add employee breakdowns, competitors, and intent.

<Info>
  Enrich Companies only works with `id` values returned by Search Companies. To search and reveal in one call, use [Search and Enrich Companies](/api-reference/search-and-enrich/search-and-enrich-companies) instead.
</Info>

## Endpoint

```
POST https://api.lusha.com/v3/companies/enrich
```

## Authentication

<ParamField header="api_key" type="string" required>
  Your Lusha API key.
</ParamField>

## Request body

<ParamField body="ids" type="string[]" required>
  Up to 100 Lusha company IDs, from a Search Companies response.

  Example: `["16303253", "12790225"]`
</ParamField>

<ParamField body="reveal" type="string[]">
  Additional data to include for each company.

  Allowed values: `employeesByDepartment`, `employeesByLocation`, `employeesBySeniority`, `competitors`, `intent`
</ParamField>

</Info>

## Error codes

| Status | Meaning |
|--------|---------|
| `400` | Bad request — invalid input data |
| `401` | Unauthorized — invalid or missing API key |
| `402` | Payment required — insufficient credits |
| `403` | Forbidden — account inactive or V3 access not enabled |
| `429` | Too many requests — rate limit exceeded |
