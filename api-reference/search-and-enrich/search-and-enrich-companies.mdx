Use this endpoint to find companies and reveal their full data in one request - it combines [Search Companies](/api-reference/search/search-companies) and [Enrich Companies](/api-reference/enrich/enrich-companies) into a single call. Provide identifiers the same way you would for Search Companies.

<Tip>
  If you need to inspect what's revealable and its credit cost before committing to a reveal, call [Search Companies](/api-reference/search/search-companies) first, then [Enrich Companies](/api-reference/enrich/enrich-companies) separately. Use this combined endpoint when you already know you want the full profile.
</Tip>

## Endpoint

```
POST https://api.lusha.com/v3/companies/search-and-enrich
```

## Authentication

<ParamField header="api_key" type="string" required>
  Your Lusha API key.
</ParamField>

## Accepted identifiers

Each company in the `companies` array needs **at least one** of the following:

- Lusha company `id`
- `name`
- `domain`

## Request body

<ParamField body="companies" type="array" required>
  Up to 100 companies to find and enrich.

  <Expandable title="company fields">
    <ParamField body="companies[].clientReferenceId" type="string">
      Your own reference ID for this company. Echoed back on the matching result.

      Example: `comp-ref-1`
    </ParamField>

    <ParamField body="companies[].id" type="string">A Lusha company ID.</ParamField>
    <ParamField body="companies[].name" type="string">The company name.</ParamField>
    <ParamField body="companies[].domain" type="string">The company domain.</ParamField>
  </Expandable>
</ParamField>

<ParamField body="options" type="object">
  <Expandable title="options fields">
    <ParamField body="options.includePartialProfiles" type="boolean">
      When `true`, includes companies with incomplete data in the results instead of dropping them.
    </ParamField>
  </Expandable>
</ParamField>

<Info>
  Unlike Search and Enrich Contacts, this endpoint doesn't take a `reveal` field - every matched company returns full firmographics automatically.
</Info>

## Response

<ResponseField name="requestId" type="string">
  Unique ID for this request, in UUID format.
</ResponseField>

<ResponseField name="results" type="object[]">
  One entry per company you searched for. Each result has the same shape as an [Enrich Companies](/api-reference/enrich/enrich-companies) result, plus `clientReferenceId`.

  <Expandable title="result fields">
    <ResponseField name="results[].clientReferenceId" type="string">Echoes the `clientReferenceId` you sent for this company.</ResponseField>
    <ResponseField name="results[].id" type="string" />
    <ResponseField name="results[].name" type="string" />
    <ResponseField name="results[].domain" type="string" />
    <ResponseField name="results[].description" type="string" />
    <ResponseField name="results[].companyType" type="string" />
    <ResponseField name="results[].yearFounded" type="number" />
    <ResponseField name="results[].employeeCount" type="object">`exact`, `min`, and `max` headcount.</ResponseField>
    <ResponseField name="results[].industry" type="string" />
    <ResponseField name="results[].subIndustry" type="string" />
    <ResponseField name="results[].location" type="object">HQ location.</ResponseField>
    <ResponseField name="results[].additionalLocations" type="object[]">All other known company sites.</ResponseField>
    <ResponseField name="results[].socialLinks" type="object">`linkedin`, `facebook`, and `x` URLs, plus `instagram`, `youtube`, and `tiktok` URL lists. Each is omitted when Lusha has no data for it.</ResponseField>
    <ResponseField name="results[].revenueRange" type="object">`min` and `max` revenue estimates.</ResponseField>
    <ResponseField name="results[].funding" type="object">Funding history, when available.</ResponseField>
    <ResponseField name="results[].technologies" type="string[]" />
    <ResponseField name="results[].businessModel" type="string[]" />
    <ResponseField name="results[].alternativeName" type="string">Other name the company is known by.</ResponseField>
    <ResponseField name="results[].alternativeDomains" type="string[]">Other domains the company uses.</ResponseField>
    <ResponseField name="results[].companyOffering" type="string">Short description of what the company sells or does.</ResponseField>
    <ResponseField name="results[].emailDomain" type="string">Primary domain used for company email addresses.</ResponseField>
    <ResponseField name="results[].email" type="string">Company contact email address.</ResponseField>
    <ResponseField name="results[].phone" type="string">Company phone number.</ResponseField>
    <ResponseField name="results[].logoUrl" type="string">URL of the company logo.</ResponseField>
    <ResponseField name="results[].additionalIndustries" type="object[]">Up to 2 secondary `industry` / `subIndustry` pairs.</ResponseField>
    <ResponseField name="results[].specialities" type="string[]">Company specialities.</ResponseField>
    <ResponseField name="results[].specialitiesRefactored" type="string[]">Normalized version of `specialities`.</ResponseField>
    <ResponseField name="results[].keywords" type="string[]">Keywords associated with the company, normalized from specialities and description.</ResponseField>
    <ResponseField name="results[].industryTags" type="string[]">Industry tags.</ResponseField>
    <ResponseField name="results[].sicCodes" type="object[]">SIC codes, each with `code` and `description`.</ResponseField>
    <ResponseField name="results[].naicsCodes" type="object[]">NAICS codes, each with `code` and `description`.</ResponseField>
    <ResponseField name="results[].linkedinFollowers" type="number">LinkedIn follower count.</ResponseField>
    <ResponseField name="results[].popularityTier" type="number">Popularity tier. Example: `1`</ResponseField>

    <Info>
      The fields below are returned only when you name them in `reveal`. They have the same shape as on [Enrich Companies](/api-reference/enrich/enrich-companies).
    </Info>

    <ResponseField name="results[].employeesByDepartment" type="object[]">Headcount by `department`, with `count`. Requires `employeesByDepartment`.</ResponseField>
    <ResponseField name="results[].employeesByLocation" type="object[]">Headcount by `country` and `state`, with `count`. Requires `employeesByLocation`.</ResponseField>
    <ResponseField name="results[].employeesBySeniority" type="object[]">Headcount by `seniority`, with `count`. Requires `employeesBySeniority`.</ResponseField>
    <ResponseField name="results[].competitors" type="object[]">Competitor companies, each with `id`, `name`, and `domain`. Requires `competitors`.</ResponseField>
    <ResponseField name="results[].intent" type="object">Intent data for the topics configured on your account. Requires `intent`.</ResponseField>
    <ResponseField name="results[].estimatedAnnualItSpend" type="object">`value`, `currency`, and `valueUsd`. Requires `estimatedAnnualItSpend`.</ResponseField>
    <ResponseField name="results[].monthlyWebsiteTraffic" type="object">`visits`, `momChangePercent`, and `month`. Requires `monthlyWebsiteTraffic`.</ResponseField>
    <ResponseField name="results[].openJobs" type="object">`total`, `byDepartment`, `byLocation`, and `bySeniority` open-job counts. Each requires its own token: `openJobsTotal`, `openJobsByDepartment`, `openJobsByLocation`, `openJobsBySeniority`.</ResponseField>
    <ResponseField name="results[].directParent" type="object">The company's immediate parent: `lushaCompanyId`, `name`, `domain`, and `hqCountry`. `null` when there is no known parent. Requires `directParent`.</ResponseField>
    <ResponseField name="results[].ultimateParent" type="object">The company at the top of its ownership tree, same shape as `directParent`. Requires `ultimateParent`.</ResponseField>

    <ResponseField name="results[].error" type="object">
      Present instead of profile data when the lookup or enrich fails for this company.

      <Expandable title="properties">
        <ResponseField name="code" type="string">One of `NOT_FOUND`, `COMPLIANCE_RESTRICTED`, `ENRICH_FAILED`.</ResponseField>
        <ResponseField name="message" type="string">Human-readable description.</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="billing" type="object">
  <Expandable title="properties">
    <ResponseField name="creditsCharged" type="integer">Credits charged for this request.</ResponseField>
    <ResponseField name="resultsReturned" type="integer">Number of successful results.</ResponseField>
  </Expandable>
</ResponseField>

<Info>
  **Billing:** Same as Enrich Companies - charged per successful result via the `reveal_company` action.
</Info>

## Error codes

| Status | Meaning |
|--------|---------|
| `400` | Bad request - invalid input data |
| `401` | Unauthorized - invalid or missing API key |
| `402` | Payment required - insufficient credits |
| `403` | Forbidden - account inactive or V3 access not enabled |
| `429` | Too many requests - rate limit exceeded |

## Example

<CodeGroup>

```bash cURL
curl --request POST \
  --url https://api.lusha.com/v3/companies/search-and-enrich \
  --header 'api_key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "companies": [
      { "clientReferenceId": "comp-ref-1", "name": "Lusha" },
      { "clientReferenceId": "comp-ref-2", "domain": "salesforce.com" }
    ],
    "options": {
      "includePartialProfiles": true
    }
  }'
```
