Contact Lookalikes finds contacts similar to a set of seed contacts using AI-powered recommendations. Provide 5–100 seed contacts via LinkedIn URLs, emails, Lusha IDs, or name + company, and the API returns contacts who share similar roles, seniority, and company profiles.

## Endpoint

```
POST https://api.lusha.com/v3/contacts/lookalike
```

**Authentication:** API key (`api_key` header)

## Pagination without duplicates

On your first request, omit `dedupeSessionId` — the server generates one and returns it. Pass it on every subsequent request to get more results without repeating contacts already seen. Sessions are retained for 30 days.

## Request body

<ParamField body="seeds" type="object" required>
  Seed contacts to match against.

  <Expandable title="seeds fields">
    <ParamField body="seeds.linkedinUrls" type="string[]">
      LinkedIn profile URLs. Max `100` items. Example: `"https://www.linkedin.com/in/orit-shilvock-6243bb5"`
    </ParamField>

    <ParamField body="seeds.emails" type="string[]">
      Email addresses. Max `100` items. Example: `"gal.ashkelon@lusha.com"`
    </ParamField>

    <ParamField body="seeds.ids" type="string[]">
      Lusha contact IDs, as strings. Preferred over `contactIds`. Max `100` items. Example: `["1234", "4567"]`
    </ParamField>

    <ParamField body="seeds.contactIds" type="integer[]">
      Lusha contact IDs, as numbers. Legacy — prefer `ids`. Max `100` items. Example: `[1234, 4567]`
    </ParamField>

    <ParamField body="seeds.contacts" type="object[]">
      Seed contacts identified by name and company. Max `100` items.

      <Expandable title="contact object fields">
        <ParamField body="seeds.contacts[].firstName" type="string" required>
          Example: `"Miri"`
        </ParamField>

        <ParamField body="seeds.contacts[].lastName" type="string" required>
          Example: `"Tamir"`
        </ParamField>

        <ParamField body="seeds.contacts[].companyDomain" type="string">
          At least one of `companyDomain` or `companyName` is required. Example: `"lusha.com"`
        </ParamField>

        <ParamField body="seeds.contacts[].companyName" type="string">
          Example: `"Lusha"`
        </ParamField>
      </Expandable>
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="dedupeSessionId" type="string">
  Session ID returned from a previous call. Omit on the first request; include on every "get more" request.
</ParamField>

<ParamField body="exclude" type="object">
  Contacts to exclude from results, in the same shape as `seeds` (`linkedinUrls`, `emails`, `ids`, `contactIds`, `contacts`).
</ParamField>

<ParamField body="limit" type="integer" default="25">
  Results to return per call. Range: `1`–`100`.
</ParamField>

## Example requests

<CodeGroup>

```bash First request
curl --request POST \
  --url https://api.lusha.com/v3/contacts/lookalike \
  --header 'api_key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "seeds": {
      "linkedinUrls": ["https://www.linkedin.com/in/orit-shilvock-6243bb5"],
      "emails": ["gal.ashkelon@lusha.com"],
      "ids": ["1234"]
    },
    "exclude": {
      "emails": ["existing@customer.com"]
    },
    "limit": 25
  }'
```

```bash Second request
curl --request POST \
  --url https://api.lusha.com/v3/contacts/lookalike \
  --header 'api_key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "dedupeSessionId": "58adaa77-7a6e-4c9b-8c2d-820a6538e613",
    "seeds": {
      "linkedinUrls": ["https://www.linkedin.com/in/shmulikwillinger"]
    },
    "limit": 25
  }'
```

</CodeGroup>

## Response

### 200 — Success

<ResponseField name="dedupeSessionId" type="string">
  Session ID to use for subsequent "get more" requests. Can be `null` when there are no results on the first request.
</ResponseField>

<ResponseField name="results" type="object[]">
  Array of lookalike contacts.

  <Expandable title="result fields">
    <ResponseField name="results[].id" type="string">
      Lusha contact ID. Example: `"4389064624"`
    </ResponseField>

    <ResponseField name="results[].firstName" type="string" />
    <ResponseField name="results[].lastName" type="string" />

    <ResponseField name="results[].socialLinks" type="object">
      `linkedin` profile URL.
    </ResponseField>

    <ResponseField name="results[].company" type="object">
      `id`, `name`, and `domain` of the contact's current company.
    </ResponseField>

    <ResponseField name="results[].jobTitle" type="object">
      `title`, `departments`, and `seniority`.
    </ResponseField>

    <ResponseField name="results[].location" type="object">
      `country`, `state`, and `city`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="meta" type="object" required>
  `returned` (results in this response) and `hasMore` (whether more results are available for this `dedupeSessionId`).
</ResponseField>

<ResponseField name="billing" type="object">
  `creditsCharged` and `resultsReturned` for this request.
</ResponseField>

<Tip>
  **Billing:** Charged per result via the `lookalikeContact` action.
</Tip>

Results are lightweight previews. Pass each `id` to [Enrich Contacts](/api-reference/enrich/enrich-contacts) to reveal emails and phone numbers.

## Error codes

| Status | Meaning |
|--------|---------|
| `400` | Bad request — invalid input data. |
| `402` | Insufficient credits. |
| `403` | Forbidden — account inactive, or V3 access not enabled. |
| `410` | `dedupeSessionId` is invalid or expired — start a new run by omitting it. |
| `500` | Internal server error. |
