Company Lookalikes finds companies similar to a set of seed companies using AI-powered recommendations. Provide 5–100 seed companies via domains or LinkedIn URLs, and the API returns companies with similar size, industry, and profile.

## Endpoint

```
POST https://api.lusha.com/v3/companies/lookalike
```

**Authentication:** API key (`api_key` header)

## Pagination without duplicates

On your first request, omit `dedupeSessionId` — the server generates one and returns it. Pass it on every subsequent request to get more results without repeating companies already seen. Sessions are retained for 30 days.

## Request body

<ParamField body="seeds" type="object" required>
  Seed companies to match against. Requires at least one property.

  <Expandable title="seeds fields">
    <ParamField body="seeds.domains" type="string[]">
      Company domains. Max `100` items. Example: `["sap.com", "oracle.com"]`
    </ParamField>

    <ParamField body="seeds.linkedinUrls" type="string[]">
      Company LinkedIn URLs. Max `100` items. Example: `["https://www.linkedin.com/company/sap"]`
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="dedupeSessionId" type="string">
  Session ID returned from a previous call. Omit on the first request; include on every "get more" request.
</ParamField>

<ParamField body="exclude" type="object">
  Companies to exclude from results, in the same shape as `seeds` (`domains`, `linkedinUrls`).
</ParamField>

<ParamField body="limit" type="integer" default="25">
  Results to return per call. Range: `1`–`100`.
</ParamField>

## Example requests

<CodeGroup>

```bash First request
curl --request POST \
  --url https://api.lusha.com/v3/companies/lookalike \
  --header 'api_key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "seeds": {
      "domains": ["sap.com", "oracle.com"],
      "linkedinUrls": ["https://www.linkedin.com/company/google"]
    },
    "exclude": {
      "domains": ["existingcustomer.com"]
    },
    "limit": 100
  }'
```

```bash Second request
curl --request POST \
  --url https://api.lusha.com/v3/companies/lookalike \
  --header 'api_key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "dedupeSessionId": "58adaa77-7a6e-4c9b-8c2d-820a6538e613",
    "seeds": {
      "domains": ["sap.com"]
    },
    "limit": 100
  }'
```

</CodeGroup>

## Response

### 200 — Success

<ResponseField name="dedupeSessionId" type="string">
  Session ID to use for subsequent "get more" requests.
</ResponseField>

<ResponseField name="results" type="object[]">
  Array of lookalike companies.

  <Expandable title="result fields">
    <ResponseField name="results[].id" type="string">
      Lusha company ID. Example: `"16303253"`
    </ResponseField>

    <ResponseField name="results[].name" type="string" />
    <ResponseField name="results[].domain" type="string" />

    <ResponseField name="results[].employeeCount" type="object">
      `exact` employee count, when known.
    </ResponseField>

    <ResponseField name="results[].industry" type="string" />

    <ResponseField name="results[].location" type="object">
      `country`, `state`, and `city`.
    </ResponseField>

    <ResponseField name="results[].socialLinks" type="object">
      `linkedin` company URL.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="meta" type="object" required>
  `returned` (results in this response) and `hasMore` (whether more results are available for this `dedupeSessionId`).
</ResponseField>

<ResponseField name="billing" type="object">
  `creditsCharged` and `resultsReturned` for this request.
</ResponseField>

<Tip>
  **Billing:** Charged per result via the `lookalikeCompany` action.
</Tip>

## Error codes

| Status | Meaning |
|--------|---------|
| `400` | Bad request — invalid input data. |
| `402` | Insufficient credits. |
| `403` | Forbidden — account inactive, or V3 access not enabled. |
| `410` | `dedupeSessionId` is invalid or expired — start a new run by omitting it. |
| `500` | Internal server error. |
